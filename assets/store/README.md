# AniOTT Switch 스토어 이미지

Chrome 웹 스토어에 그대로 업로드할 수 있는 PNG 파일입니다.

| 파일                         | 크기       | 입력 위치                        |
| ---------------------------- | ---------- | -------------------------------- |
| `store-icon-128.png`         | 128 × 128  | 스토어 아이콘                    |
| `01-library-1280x800.png`    | 1280 × 800 | 스크린샷 1: 작품 보관함          |
| `02-edit-1280x800.png`       | 1280 × 800 | 스크린샷 2: 작품 정보 편집       |
| `03-settings-1280x800.png`   | 1280 × 800 | 스크린샷 3: 구독 OTT와 설정      |
| `04-overlay-1280x800.png`    | 1280 × 800 | 스크린샷 4: 작품 페이지 사이드바 |
| `05-switch-1280x800.png`     | 1280 × 800 | 스크린샷 5: 다른 OTT 찾기와 이동 |
| `promo-small-440x280.png`    | 440 × 280  | 작은 프로모션 타일, 선택 사항    |
| `promo-marquee-1400x560.png` | 1400 × 560 | 마키 프로모션 타일, 선택 사항    |

아이콘은 96 × 96 그림에 사방 16px 투명 여백을 둡니다. 캡처는 1280 × 800의 실제 확장 UI를 테두리나 바깥 여백 없이 저장합니다. [Chrome 공식 이미지 규격](https://developer.chrome.com/docs/webstore/images)을 기준으로 만들었습니다.

## 캡처 내용

캡처는 격리된 Chromium 프로필에 **실제 빌드된 확장을 설치**한 뒤 생성했습니다. 《어느 마녀가 죽을 때까지》, 《장송의 프리렌》 등 실제 작품 6개의 공식 제목·연도·대표 이미지 URL을 사용합니다. 소개는 공식 내용을 바탕으로 짧게 요약했고, 카테고리와 메모는 기능을 보여주기 위해 구성했습니다. 사용자 개인 보관함이나 로그인 프로필은 사용하지 않습니다.

사이드바 뒤의 화면도 실제 라프텔 작품 상세 페이지입니다. 네트워크 응답이나 검색 결과를 가짜로 바꾸지 않으며, 웨이브의 ‘찾아서 이동’을 실제로 실행한 상태를 캡처합니다. 표시되는 결과는 캡처 당시의 응답이며 구독 포함이나 한국 내 재생 권한을 보증하지 않습니다.

이미지는 작품 정보와 확장 기능을 함께 보여주는 캡처 안에서 사용하며, 독립된 원본 포스터 파일은 저장소나 스토어 자료 ZIP에 넣지 않습니다. 공식 상세 페이지·이미지 URL·확인 시각·이미지 크기는 [작품 출처 기록](catalogue-sources.json)에 있습니다.

`capture-provenance.json`에 버전·고정 확장 ID·캡처 조건을 기록합니다. 실제 OTT 페이지에서의 성공률과 성능 결과는 별도 검증 문서를 참고하세요.

## 재생성

```sh
npm run assets:brand
npm run build
npm run assets:store
```

개발용 Playwright Chromium과 인터넷 연결이 필요합니다. 공식 페이지·이미지가 변경되면 캡처도 달라질 수 있습니다. 일반 확장 빌드와 사용자 실행에는 이미지 생성 도구나 브라우저 자동화가 포함되지 않습니다. 벡터 원본은 `assets/brand/aniott-mark.svg`이며 PNG 아이콘은 `public/icons/`에서 패키지로 복사됩니다.
