# 필드별 로컬 DOM 수집기 진단

실행:

```sh
node eval/dom-local/browser.mjs
node eval/dom-local/replay.mjs
```

독립된 Playwright Chromium에서 `src/providers/dom-local.ts`와 `dom-links.ts`를 번들로 실행한다. 사용자 Chrome이나 로그인 세션에는 접근하지 않는다. 이미지 요청은 1440 × 1440 SVG로 응답하며 외부 네트워크에 연결하지 않는다.

수작업으로 만든 여섯 가지 개발용 HTML에서 제목·설명·이미지 후보 회수, 보수적 선택/보류, 실제 렌더링 크기, 부모 라벨, 네이티브 XPath 일치 여부를 확인한다. 추가로 점진적 탐색 중단, DOM 변경 후 XPath 무효화, 정적 링크 및 알 수 없는 JS 동작의 구분을 확인한다.

`browser-results.json`은 원시 측정, `RESULTS.md`는 해당 실행의 요약이다. 전체 HTML과 로컬 JSON의 바이트 수는 **직렬화 크기** 비교이며 브라우저 메모리 사용량으로 해석하면 안 된다. 10회 워밍업 후 50회 처리 시간을 측정한다. 범용 선택기로 활성 영역을 찾는 시간도 포함되며, 작은 수치에는 브라우저 타이머 해상도 한계가 있다.

이 자료는 모델 평가, 새로운 서비스/작품에 대한 블라인드 검증, 실제 OTT 페이지 재현이 아니다. 기존 `eval/dom-scale` 동결 실험은 변경하거나 새로운 검증 결과로 재사용하지 않는다. 작은 페이지에서는 후보의 구조화된 주변 문맥이 원본 HTML보다 커질 수도 있다.

`replay.mjs`는 이미 개발에 사용한 라프텔·프라임비디오·티빙의 공개 HTML 3개를 다시 읽는다. 실행에는 기존 로컬 `.tmp/dom-scale/train` 캡처가 필요하며 HTML 자체는 커밋하지 않는다. 기존 동결 주석과 후보 값은 읽기만 하고, 새 측정은 `replay-results.json`과 `REPLAY.md`에 기록한다. 자동 영역 선택과 호출자가 검증한 작품 영역을 지정하는 경우를 별도로 비교한다. DOMParser로 만든 분리 문서이므로 외부 CSS·실제 레이아웃·SPA 런타임은 재현되지 않는다. 설명 주석은 과거 수집기의 길이 제한 때문에 접두어 일치만 비교한다.
