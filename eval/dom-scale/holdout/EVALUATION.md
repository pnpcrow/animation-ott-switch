# 독립 미학습 검증

모델 평가 전 자료를 동결했다. 학습/모델 설계 담당자는 작품, URL, DOM 후보, 정답을 보지 않았으며 수집·주석 담당자는 모델 출력을 보거나 모델 설정을 조정하지 않았다. Netflix와 Apple TV는 서비스 전체를 학습에서 제외했고, Laftel/TVING은 별도 예약한 미학습 작품을 사용했다. 총 16개 작품 family 예약키의 SHA256만 학습 누출 방지용으로 전달했다.

## 수집 분모

| 서비스 | 실제 수집 시도 | 점수 대상 페이지 | 필드 문제 | 코호트 |
|---|---:|---:|---:|---|
| Netflix | 19 | 12 | 36 | 미학습 서비스 |
| Apple TV | 16 | 11 | 33 | 미학습 서비스 |
| Laftel | 9 | 9 | 27 | 알려진 서비스·미학습 작품 |
| TVING | 8 | 8 | 24 | 알려진 서비스·미학습 작품 |
| 합계 | 52 | 40 | 120 | |

각 페이지에서 제목·대표 이미지·작품 소개를 선택한다. 실제 작품 상세 16개, 작품 모달 6개, 소개 확장 모달 2개는 작품 정보를 추출하는 양성 페이지다. 검색 7개, 검색 랜딩 1개, 로그인 3개, 로그인 모달 1개, 구독 차단 모달 2개, 실제 전체 재생 2개는 세 필드 모두 none을 선택하는 음성 페이지다. 상세 모달 안의 미리보기 영상은 전체 재생으로 취급하지 않았다.

정적 기준선: 모델 없이 항상 none을 고르면 정답인 48필드만 맞아 **48/120 = 40.0%**다. 작품 정보를 찾아야 하는 양성 72필드의 정답 수는 0이다. 전체 정확도만으로 유용성을 판단하지 않고 양성 선택 정답 수·재현율과 none 오탐을 함께 확인한다. 실제 후보가 none 하나뿐인 자명한 문제는 2개로, 전체 120개 중 118개가 비교 선택 문제다.

| 정적 always-NONE 기준선 | 정답/분모 | 정확도 |
|---|---:|---:|
| 미학습 서비스 | 18/69 | 26.1% |
| 알려진 서비스·미학습 작품 | 30/51 | 58.8% |
| Netflix | 12/36 | 33.3% |
| Apple TV | 6/33 | 18.2% |
| Laftel | 15/27 | 55.6% |
| TVING | 15/24 | 62.5% |

제외된 12시도는 모델 출력 확인 전 정했다. 동일 로그인 중복 1개, 기존 상세로 돌아온 리다이렉트 4개, 예고편 버튼을 찾지 못해 그대로 남은 상세 2개, 로그인 클릭 후 그대로 남은 상세 1개, 인기 검색 랜딩 중복 3개, 아직 로딩 중인 로그인 모달 1개다. 이 시도들은 원본 기록과 수집 분모에서 삭제하지 않았다. 나머지 로그인·검색·차단 화면은 정상적인 none 문제로 포함했다.

실제 재생은 인증 Netflix 2개 상태에서 영상 시간이 진행되고 `paused=false`, `readyState=4`인 것을 확인했다. 다른 검증 서비스의 실제 재생 화면을 확보했다고 주장하지 않는다. 재생 직후 DOM을 기록하고 탭을 닫았다. 인증 수집은 개인정보 제외용 공용 collector를 사용했고, 공개 수집과 다른 수집 변형이라는 점을 별도 결과로 구분한다.

## 고정 후보와 채점

정답을 보지 않는 일반 수집기가 각 필드의 원본 후보 최대 18개를 수집한다. 모델에는 앞의 12개와 none만 제공한다. 후보 순서는 정답과 무관한 해시로 섞는다. 현재 작품이 실제 존재하지만 고정 후보에서 누락된 3문제(제목 1, 이미지 2)는 모든 모델에서 실패로 남긴다. 이 문제를 none 정답으로 바꾸거나 후보를 삽입하지 않는다. 전체 120문제 정확도와 후보가 있는 117문제 조건부 정확도를 함께 보고한다.

`score.mjs`는 데이터 동결 해시, 입력 계획 해시, 120문제 ID, 문제별 후보 ID 집합을 확인한 후 채점한다. 실행 실패나 잘못된 ID도 실패로 센다. 전체·필드·서비스·코호트·화면 상태·공개/인증 수집별 결과, none 오탐과 미탐, 페이지의 세 필드가 모두 맞는 비율을 분리한다. 신뢰구간은 같은 작품의 페이지와 필드를 묶어 작품 family 단위 2,000회 재표집한다.

새로 학습한 세 조건을 주평가로 비교한다. 과거 Netflix/Apple 개발 자료에 노출되었을 수 있는 이전 모델은 엄격한 미학습 서비스 비교에 넣지 않는다. 브라우저 메모리와 브라우저 처리 시간은 별도 실제 브라우저 실행으로 측정하며 Python CPU 추론 시간을 대신 사용하지 않는다. 실행 백엔드와 Chromium 환경을 결과에 명시한다.

개발 결과에 따른 보충 조건: held-out 결과를 열기 전, 개발 검증에서 compact 12층 조건이 모두 none을 선택하는 붕괴가 관찰되어 부모 작업에서 4층·원래 natural384 표현의 `small-natural` 조건을 추가하기로 했다. 같은 seed·3 epoch·분할을 유지하며 원래 세 조건과 자료·정답을 보존한다. 이 네 번째 조건은 최초 계획에 있던 조건으로 포장하지 않고 보충 결과로 분리해 보고한다. 별도 `supplemental-evaluation-plan.json`과 wrapper로 같은 120문제, 같은 동결 지표를 적용한다. 최종 브라우저 조건 선택도 개발 검증만으로 한다.

보충 조건의 배치 선택도 held-out 실행 전에 수정했다. 개발 q8 정확도가 full 42/57, micro2 40/57이고 선택 일치가 50/57이어서, 부모 작업은 브라우저 최종 조건을 full batch로 골랐다. native full/micro2 결과는 둘 다 보고한다. 초기 보충 계획·wrapper는 `supplemental-history/`에 보존했고, 변경 시각·이전 해시·이유를 새 보충 계획에 기록했다. 이는 held-out 결과에 따른 선택 변경이 아니다.

모델 가중치와 전처리 동결 이후 실행하여 `scores.json`에 기록한다. 아직 추론 결과를 열지 않았다.

분석 계획 변경 이력: 모델 출력 열람 전, 2026-11-13 UTC에 두 조건이 모두 실행 실패해 `selected=null`인 경우를 선택 일치에 포함하지 않도록 수정했다. 두 조건 모두 유효한 후보를 선택한 문제 수를 별도 분모로 기록한다. 이전 scorer SHA256은 `a83b11896989c3a6dd8e0b59e0c4f1ac844835bb56539a882036293104a8fa3d`, 수정 후는 `980857b519099dda07b9480a4f8b88835244c2ba230d7930242960f65d8311a5`다. 입력·정답·데이터 동결 해시는 바꾸지 않았다.

이 검증은 수집된 DOM 후보에서 올바른 요소를 선택하는 능력을 측정한다. 서비스 2개가 미학습이었다는 결과를 모든 OTT에 대한 일반화로 확대할 수 없으며, OTT 간 작품 동일성·지역 제공 여부·구독 권한·확장기능의 실제 화면 이동까지 종합 검증한 결과도 아니다.
