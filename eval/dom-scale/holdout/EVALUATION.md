# 독립 미학습 검증

모델 평가 전 자료를 동결했다. 학습/모델 설계 담당자는 작품, URL, DOM 후보, 정답을 보지 않았으며 수집·주석 담당자는 모델 출력을 보거나 모델 설정을 조정하지 않았다. Netflix와 Apple TV는 서비스 전체를 학습에서 제외했고, Laftel/TVING은 별도 예약한 미학습 작품을 사용했다. 총 16개 작품 family 예약키의 SHA256만 학습 누출 방지용으로 전달했다.

## 수집 분모

| 서비스 | 실제 수집 시도 | 점수 대상 페이지 | 필드 문제 | 코호트 |
|---|---:|---:|---:|---|
| Netflix | 19 | 12 | 36 | 미학습 서비스 |
| Apple TV | 16 | 11 | 33 | 미학습 서비스 |
| Laftel | 9 | 9 | 27 | 알려진 서비스·미학습 작품 |
| TVING | 8 | 8 | 24 | 알려진 서비스·미학습 작품 |
| 합계 | 52 | 40 | 120 | |

각 페이지에서 제목·대표 이미지·작품 소개를 선택한다. 실제 작품 상세 16개, 작품 모달 6개, 소개 확장 모달 2개는 작품 정보를 추출하는 양성 페이지다. 검색 7개, 검색 랜딩 1개, 로그인 3개, 로그인 모달 1개, 구독 차단 모달 2개, 실제 전체 재생 2개는 세 필드 모두 none을 선택하는 음성 페이지다. 상세 모달 안의 미리보기 영상은 전체 재생으로 취급하지 않았다.

제외된 12시도는 모델 출력 확인 전 정했다. 동일 로그인 중복 1개, 기존 상세로 돌아온 리다이렉트 4개, 예고편 버튼을 찾지 못해 그대로 남은 상세 2개, 로그인 클릭 후 그대로 남은 상세 1개, 인기 검색 랜딩 중복 3개, 아직 로딩 중인 로그인 모달 1개다. 이 시도들은 원본 기록과 수집 분모에서 삭제하지 않았다. 나머지 로그인·검색·차단 화면은 정상적인 none 문제로 포함했다.

실제 재생은 인증 Netflix 2개 상태에서 영상 시간이 진행되고 `paused=false`, `readyState=4`인 것을 확인했다. 다른 검증 서비스의 실제 재생 화면을 확보했다고 주장하지 않는다. 재생 직후 DOM을 기록하고 탭을 닫았다. 인증 수집은 개인정보 제외용 공용 collector를 사용했고, 공개 수집과 다른 수집 변형이라는 점을 별도 결과로 구분한다.

## 고정 후보와 채점

정답을 보지 않는 일반 수집기가 각 필드의 원본 후보 최대 18개를 수집한다. 모델에는 앞의 12개와 none만 제공한다. 후보 순서는 정답과 무관한 해시로 섞는다. 현재 작품이 실제 존재하지만 고정 후보에서 누락된 3문제(제목 1, 이미지 2)는 모든 모델에서 실패로 남긴다. 이 문제를 none 정답으로 바꾸거나 후보를 삽입하지 않는다. 전체 120문제 정확도와 후보가 있는 117문제 조건부 정확도를 함께 보고한다.

`score.mjs`는 데이터 동결 해시, 입력 계획 해시, 120문제 ID, 문제별 후보 ID 집합을 확인한 후 채점한다. 실행 실패나 잘못된 ID도 실패로 센다. 전체·필드·서비스·코호트·화면 상태·공개/인증 수집별 결과, none 오탐과 미탐, 페이지의 세 필드가 모두 맞는 비율을 분리한다. 신뢰구간은 같은 작품의 페이지와 필드를 묶어 작품 family 단위 2,000회 재표집한다.

새로 학습한 세 조건만 주평가로 비교한다. 과거 Netflix/Apple 개발 자료에 노출되었을 수 있는 이전 모델은 엄격한 미학습 서비스 비교에 넣지 않는다. 브라우저 메모리와 WebGPU 시간은 별도 실제 Chrome 실행 결과이며 Python CPU 추론 시간을 대신 사용하지 않는다.
