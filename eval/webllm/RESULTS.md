# WebLLM 실제 실행 결과 · 2026-11-13

**세 모델 모두 작품 자동 이동 판정에 사용할 근거가 부족했습니다.** 선택형 평가 도구는 실제 WebGPU에서 동작하지만 확장 기능에는 연결하지 않았습니다. 기본 검색·추출·상세 검증 경로를 유지합니다. JSON 형식을 강제하는 것과 정확한 작품 판정은 별개의 문제였습니다.

## 실행 범위

- Windows, AMD Radeon 780M / WebGPU `amd`, `rdna-3`, `shader-f16=true`.
- 독립 Chromium 프로필, `@mlc-ai/web-llm@0.2.88`, Web Worker, context 4096, temperature 0, seed 7, max output 240 tokens.
- 실제 공개 관측으로 만든 [8개 작품 자료](../../qa/cross-check/webllm-eight-works.json). 조정용 4개: 어느 마녀·프리렌·약사·니아. 독립 검증용 4개: 사쿠라·Re:제로·던전밥·수수께끼.
- v1/v2와 작성된 조정 사례에서 수정한 v3를 실제 8개 자료 실행 전에 고정했습니다. 각 모델의 조정용 4개에서 템플릿을 선택한 뒤 해당 템플릿만 검증용 4개에 한 번 실행했습니다. 검증 결과를 보고 프롬프트·정답을 바꾸지 않았습니다. 모델 선택을 검증 점수로 최적화하지 않았습니다.
- 원본 답·추론 시간·사용량·자료/템플릿 해시를 저장했습니다. 관측 자료, 정답과 공개 출처는 별도로 보관하며 모델에는 `input`만 전달합니다.

모델 가중치 크기는 공식 `ndarray-cache.json`의 `ParamBytes`를 확인한 값이며 tokenizer·WASM·캐시 부가 데이터는 제외합니다. GPU 메모리는 설치한 WebLLM의 공식 카탈로그 값이고 실제 사용량을 측정한 값은 아닙니다.

## 점수

`전체 일치`는 제목·이미지·소개 ID와 후보 ID·판정이 모두 정답이고 출력 검증을 통과한 경우입니다. `유효`는 관측 ID·필드 형식·판정/후보의 일관성을 통과한 수입니다. `부적절한 일치`는 보수적 정답이 보류·중복 또는 다른 후보인데 모델이 단일 일치를 주장한 횟수입니다. 이는 근거 부족·판본 혼동을 포함하며 모두 실제로 다른 작품임을 뜻하지 않습니다. 예를 들어 니아의 짧은 제목과 긴 부제는 관측된 별칭 근거가 없어 정답을 보류했습니다.

`부적절한 일치=0`만으로 사용할 수 있다고 판단하지 않습니다. 1.5B v2는 조정용 응답 4개 모두 `unknown`과 비어 있지 않은 후보 ID를 함께 내보내 거부됐습니다. 현재 도구는 조정용 출력 전부 유효·부적절한 일치 0개·런타임 오류 0개·전체 일치 75% 이상을 개발 단계의 최소 선별 조건으로 기록합니다. **세 모델 모두 이 조건을 충족하지 못했습니다.** 앞의 두 모델에 대한 이 조건의 적용은 조정 결과의 사후 점검이며, 3B 실행에는 같은 조건을 코드로 적용했습니다. 선택된 템플릿의 검증 실행은 원인 분석용이고 모델 사용 추천이 아닙니다. 작은 자료의 선별 조건을 통과하더라도 자동 이동은 허용하지 않습니다.

## 해석의 한계와 수정

실제 8개 자료는 각 종류별 제목·이미지·소개 후보가 최대 하나입니다. 따라서 해당 필드의 높은 일치율은 관측 ID 선택과 누락 처리 확인이며, 복잡한 원본 DOM에서 정확한 메타데이터를 찾아낸다는 증거가 아닙니다. 사이트 홍보 문구와 작품 제목이 경쟁하는 상황은 별도의 작성된 회귀 자료로 확인했고, 일반 DOM 수집 명령은 공개 라프텔 페이지에서 실행했습니다. 실제 DOM 구조가 바뀐 경우의 독립 자료를 더 모아야 합니다.

Qwen3의 `enable_thinking=false` 응답에도 런타임이 빈 `<think>` 블록을 붙이는 동작을 실제로 확인했습니다. 공식 런타임 구현에 맞춰 빈 블록만 제거하고, 비어 있지 않은 추론·임의 설명에서 JSON을 추출하거나 고치지 않습니다. Qwen2.5에는 Qwen3용 옵션을 전달하지 않습니다. 모델이 만든 URL은 받지 않고 관측된 ID만 허용하며, `unknown`과 후보 지정의 모순·불완전 검색에서의 부재 판정을 거부합니다.

일반 DOM 수집은 `h1`, 메타 태그, 주요 이미지·문단·공식 작품 링크를 제한된 크기로 기록합니다. 숨은/내비게이션 링크, 빈 이미지/주소, 해시 전용 링크는 제외합니다. 검색 완료 여부를 추측하거나 URL 없는 카드를 클릭하지 않습니다. 사이트별 기본 추출과 상세 재검증을 대체하는 기능이 아닙니다.

확장 설치·일반 빌드에 WebLLM 의존성이나 모델을 추가하지 않았습니다. 평가 화면 초기 진입의 외부 요청 0건, 실제 GPU 로드·추론·해제, 계약/수집 회귀 테스트 7개를 확인했습니다. 다운로드한 모델은 독립 평가 프로필의 캐시에 남아 있고 평가 도구의 삭제 버튼으로 제거할 수 있습니다.
