# 저장소 공개 전 점검

2026-11-14 · 기준 커밋 `af0e6d13f25a9a44e14f4c3bf71c0cd46025cd1f` (`v0.1.6`)

AniOTT Switch의 비공개 저장소를 공개하기 전에 아래 범위를 확인했다. 이 문서는 점검 결과이며 모든 종류의 개인정보·비밀정보를 자동으로 검출했다는 보증은 아니다.

## 확인 범위

- 기준 시점의 추적 파일 665개, `main` 이력 50개 커밋에서 도달 가능한 고유 blob 842개(약 138 MB)를 패턴 검사했다. 압축 JSON 8개도 풀어서 확인했다.
- 원격 `main` 및 `v0.1.0`부터 `v0.1.6`까지 모든 태그의 대상 커밋이 이 이력에 포함됨을 확인했다.
- 기존 GitHub 릴리즈 7개의 첨부 파일 16개는 로컬 파일과 크기·SHA-256이 일치했다. ZIP 7개는 내부 10개 파일을 각각 열어 같은 비밀정보 패턴을 검사했다.
- 개인 이메일, GitHub/OpenAI 토큰, AWS 접근키 형태, JWT, 비밀키, 인증 필드와 서명 URL 등을 확인하고 검출 항목을 분류했다. Git 커밋 작성자 이메일은 GitHub의 noreply 주소였다.
- 실제 원본 페이지 HTML·화면 캡처·브라우저 프로필이 저장되는 `.tmp/`, `artifacts/`, 빌드/릴리즈 작업 폴더와 `.env*`는 Git에서 제외됨을 확인했다.

## 결과와 조치

활성 애플리케이션 비밀키, 사용자 계정 인증 토큰, 개인 이메일, 계정 저장소 덤프는 이 점검에서 발견되지 않았다. `manifest.key`는 스토어 확장 ID를 유지하기 위한 **공개키**다. 비밀키 헤더 패턴은 입력 거부를 검사하는 테스트 문자열이었고, 로컬 사용자 경로 후보는 OTT의 `/home/…` URL이었다.

평가 데이터 4개 파일에는 공개 페이지의 검색 아이콘을 가리키는 제3자 S3 서명 URL이 각각 한 번 남아 있었다. 사용자 계정이나 영상 주소가 아닌 이미지 URL이며, 서명 시각은 2026-11-13 12:04:06 UTC, 유효기간은 1,800초로 점검 시점에는 만료 상태였다. 현재 파일에서는 이 URL의 전체 쿼리만 제거했다. 원래 URL의 호스트·경로, 후보 ID·순서, 정답, 모델 출력과 성능 수치는 변경하지 않았다.

정제한 파일과 변경 전후 SHA-256은 [정제 기록](../eval/publication-sanitization.json)에 있다. 기존 동결 manifest와 평가 보고서의 과거 해시, 태그와 커밋은 보존했다. 따라서 **과거 Git 이력에도 만료된 URL은 남아 있으며, 이력을 정제했다고 주장하지 않는다.** 당시 원본 바이트 재현에는 `v0.1.6`을 사용하고, 현재 공개본은 정제 기록의 정확한 해시로 검사한다. 현재 파일로 과거의 원본 바이트를 요구하는 별도 재현 명령을 실행하면 동결 해시 검사가 거부할 수 있다.

정제 후 `npm run test:light-dom` 34개 및 `npm run test:decision-eval-v2` 49개 테스트가 통과했다. 원래 동결 해시와 정확히 연결된 4개 변경만 허용하며 일반적인 해시 불일치를 무시하지 않는다. 릴리즈 첨부 파일에서는 위 서명 URL이나 검사 대상 인증정보 패턴을 발견하지 않았다.

## 평가 데이터와 화면 자료

추적된 실제 페이지 자료는 제목·설명·이미지 URL·DOM 주변 구조 등의 제한된 관측과 평가 결과다. 전체 OTT HTML, 실제 영상, 원본 포스터 이미지 또는 로그인 프로필 전체를 배포하지 않는다. 로그인 화면 수집본도 계정 필드, 쿠키, 사용자 저장소, 영상 URL을 포함하지 않도록 만든 수집기의 제한된 결과이며, JSON의 계정·인증 관련 필드도 별도 확인했다. 개인 프로필명과 프로필 이미지가 포함되지 않도록 수집 경로를 검토했다.

서비스 이름·작품 제목·설명 등 제3자 자료의 권리는 해당 권리자에게 있다. 이 점검이 제3자 자료에 새로운 사용권을 부여하는 것은 아니다. 스토어 홍보용 캡처에는 별도로 만든 예시 작품과 자체 제작 이미지를 사용한다.

신규 릴리즈와 스토어 자산은 이 기준 이후에 추가되므로 최종 패키징 단계에서 별도로 확인한다.
