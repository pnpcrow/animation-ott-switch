# 필드별 국소 DOM 수집

전체 문서를 한 번에 분류하는 대신, 현재 작품 영역에서 필요한 필드의 후보만 찾고 각 후보 주변의 제한된 구조를 판단 입력으로 만든다. 모델 정확도와 후보 수집 성공률은 별도로 측정한다.

## 작품 정보

`src/providers/dom-local.ts`의 `createDomFieldScanner`는 검증된 요소 또는 문서를 받아 `next()`마다 후보 묶음을 반환한다. 문서가 주어지면 보이는 모달, main, body 순서로 범위를 정한다. 넷플릭스·라프텔처럼 작품 ID를 확인하는 서비스는 기존 어댑터가 검증한 루트를 직접 전달한다. 범위 발견에 사용하는 브라우저 선택자 쿼리는 방문 상한과 별개다.

- 제목: h1, itemprop, title/heading 의미 토큰과 가까운 hero/detail 영역을 참고한다. 텍스트가 없는 h1 안의 제목 이미지 alt도 제한된 깊이에서 읽는다. subtitle, 회차, 추천, 링크/버튼 내부 제목을 제외한다.
- 설명: synopsis/summary/description/plot/overview 단서를 우선한다. 명시적인 synopsis/summary/description 버튼에 담긴 펼치기 전 소개도 읽는다. 일반 p는 약한 후보이며 article/body라는 이름만으로 소개 문구라고 확정하지 않는다.
- 이미지: img src 또는 video poster와 alt, 상위 라벨, 실제 표시 크기, 원본 크기를 함께 기록한다. 작은 서비스 로고는 원본 해상도가 높아도 제외한다. 레이아웃이 없는 HTML 파서에서는 크기를 미확인으로 남긴다.

기본 방문 상한은 1,200회, 후보 상한은 필드당 12개다. 텍스트는 최대 32개 근접 노드·깊이 4·제목 180자/설명 3,000자로 제한한다. 잘린 후보를 완전한 문구로 확정하지 않는다. `sliceSize`는 재개 간격이며, 한 후보를 온전히 읽는 데 최대 35회 추가 방문이 생길 수 있다. `close()`는 탐색 커서를 비운다. 스캐너와 반환된 후보의 요소 참조는 호출자가 처리를 끝내면 버려야 한다.

`localDecisionInput`은 필드별 질문, 선택 ID 또는 null이라는 출력 규칙, 현재 작품명(선택), 후보 값과 짧은 구조를 직렬화한다. 페이지 문구를 지시로 따르지 않도록 명시하며, DOM 객체·전체 HTML·스크립트 본문·CSS 해시·휴리스틱 점수를 전달하지 않는다. class 이름은 의미 단서이며 정답이나 확률이 아니다. 현 학습 실험의 입력 형식과 자동 호환되지 않으므로 새 템플릿으로 재학습·평가하기 전에는 모델 응답을 제품 판정에 사용하지 않는다.

상대 XPath는 현재 루트 안의 스냅샷 위치다. 사이트별 영구 선택자나 모델의 서비스 식별 특징으로 사용하지 않는다. 비동기 응답은 `revalidateLocalCandidate`로 동일 요소, 값, 가시성을 재검사할 수 있다. 동적 DOM이 바뀌었다면 다시 수집한다.

## 작품 링크

`src/providers/dom-links.ts`는 href/data-href/data-url/GET action과 엄격한 정적 URL 이동 구문을 읽는다. 후보의 자기 요소, 바로 위 부모, 앞뒤 형제에 대해 짧은 텍스트·역할·라벨을 남긴다. 기본 상한은 1,500회 방문과 24개 후보다.

`location.assign('/detail/…')` 같은 리터럴은 주소 근거로 사용할 수 있지만 변수·계산식·프레임워크 이벤트 핸들러는 unknown으로 남긴다. JS를 실행하거나 번들 스크립트를 뒤지지 않는다. href를 가진 요소도 onclick이 목적지를 바꿀 수 있으면 href만 믿지 않는다. 계정·구매·다운로드 등은 작품 이동 후보에서 제외한다.

검색 경로는 이 근거 중 지원 서비스의 안전한 상세 URL과 자기 요소의 제목이 있는 후보만 보충한다. 주변 작품 제목을 빌리지 않고, 기존 제목 일치·작품 ID·상세 페이지 재확인을 유지한다. URL 없는 웨이브·애니플러스 액션은 기존 스냅샷 검증 후 정상 클릭하는 경로를 사용한다.

## 적용과 검증 범위

기존 JSON-LD·메타데이터·서비스 어댑터의 유효한 값을 보존하고 누락된 필드만 보완한다. 완결된 수집 결과에서 강한 후보가 하나로 합의할 때만 기본 추출기로 채택한다. 수집 상한에 걸리거나 여러 작품이 경쟁하면 보류한다. 이는 모든 서비스 변경을 해결하는 범용 모델이라는 의미가 아니다.

단위 검증은 모달 배경 오염, 늦게 나타나는 제목, 회차/추천, 중첩 링크, 짧게 잘린 텍스트, 이미지 크기, XPath 변경, 탐색 상한과 중단을 다룬다. 별도 Chromium 진단은 [eval/dom-local](../eval/dom-local/)에 기록한다. 이전 실험에서 사용한 실제 HTML 재생은 개발용 진단이며 새로운 블라인드 검증이 아니다. 후보 재현율·입력 크기·수집 시간은 학습 모델의 최종 정확도와 구분한다.

2026-11-14 로컬 검증: TypeScript, 단위 테스트 413개, 확장 빌드 통과. 기존 Playwright 28개 통과 후 검색 소유 경계의 마지막 보강과 JS URL 이동 테스트 2개를 추가하고 관련 9개를 재실행해 통과했다(서로 다른 브라우저 검사 30개). JS URL 후보도 실제 상세 제목이 다르면 이동을 거부한다.

합성 Chromium 자료는 18개 필드 검사와 주석된 후보 17/17 회수를 확인했다. 사용한 공개 DOM 3개 서비스에서는 후보 8/9를 회수했다. 프라임 이미지 1개는 메타데이터/별도 picture 소스에 있어 누락되고, 티빙은 경쟁 후보 때문에 기본 선택기가 보류한다. 실제 브라우저 RAM 감소나 학습 모델 정확도 향상을 측정한 결과는 아니다.

첫 기능 커밋의 [GitHub Actions 실행](https://github.com/pnpcrow/animation-ott-switch/actions/runs/43463115012)은 계정 Actions 예산 제한 때문에 작업이 시작되지 않았다. 원격 CI 통과를 주장하지 않으며 로컬 검증과 구분한다.
