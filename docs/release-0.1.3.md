# 0.1.3 · 웨이브 작품 이동과 프라임 검색 보완

2026-11-13 · 비공개 알파

웨이브의 검색 결과가 표시되어도 이동하지 못하던 원인은 카드에 작품 URL이 없고 클릭 후에 주소가 정해지는 구조였습니다. 이제 제목이 일치하는 프로그램·영화 카드가 하나일 때 임시 탭에서 정상 클릭하고, 이동한 공식 주소와 상세 제목을 다시 확인한 후 스위치합니다. 에피소드·추천 카드와 동명 중복을 임의로 고르지 않습니다. 작품 로고 제목·대표 이미지·전체 소개를 읽고 `landing=season`을 유지합니다.

Prime Video는 공식 `phrase` URL로 검색하되 페이지 전체 이동 후 비어 있는 공식 검색창에 검색어를 한 번 표시합니다. 폼을 제출하거나 포커스를 옮기지 않으며 사용자 입력·삭제를 덮어쓰지 않습니다. 한국어 `프라임 비디오:`를 포함한 지원 OTT 서비스명 접두사·접미사를 공통 정제합니다.

설정과 사이드바에 검색 캐시 초기화를 제공합니다. 메모리 검색 결과·원본 제목 재조회 캐시와 북마크의 자동 검색 연결을 지우고, 직접 연결·현재 페이지 링크와 북마크 표시 정보·카테고리·메모를 보존합니다. 초기화 이전 작업의 늦은 결과로 자동 이동하지 않습니다. 사이트 쿠키·로그인과 브라우저 전체 캐시는 지우지 않으며 공개 HTTP 재조회는 `no-store`를 사용합니다.

WebLLM 없이 기본 기능을 먼저 안정화합니다. WebLLM은 이후 선택 기능으로 검토하며 이번 버전에 모델 의존성이나 모델 다운로드는 없습니다.

타입 검사·빌드, 단위 테스트 305개와 브라우저 회귀 테스트 23개가 통과했습니다.

실제 공개 웨이브 검색을 확장에서 실행해 `어느 마녀가 죽을 때까지` 카드를 열고, [작품 상세 주소](https://www.wavve.com/player/vod?programid=CF02_CF0000000119&landing=season)와 제목을 검증한 뒤 최종 탭 이동까지 확인했습니다. 로그인 후 구독 권한·본편 재생은 검증 범위에 포함하지 않았습니다. 사이트별 전체 계정·카탈로그 호환성을 보장하는 버전은 아닙니다.

`ott-switch-0.1.3.zip`을 풀어 기존에 로드한 폴더의 파일을 교체한 뒤 `chrome://extensions`에서 확장을 새로고침하세요. 열려 있는 OTT 페이지도 새로고침해야 새 코드가 적용됩니다. 보관함을 유지하려면 확장을 제거하지 마세요.
