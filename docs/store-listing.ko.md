# AniOTT Switch 스토어 등록 문구

작성일: 2026-11-14 · 제출 대상: 0.1.8 · 기존 스토어 ID: `cmaijknliglhgokkmijggladebokgafl`

아래 내용은 저장소 코드와 현재 Chrome 공식 안내를 대조해 작성한 제출용 문구입니다. 기존 스토어 항목에 새 ZIP을 올려 사용합니다. 공개 저장소 전환 후 개인정보처리방침 URL이 로그인 없이 열리는지 확인합니다.

## 제품 정보

**이름**

```text
AniOTT Switch
```

**짧은 설명**

```text
보고 싶은 작품을 다른 OTT에서 찾아 이동하고, 작품 보관함에 저장·분류하세요.
```

**언어:** 한국어 · **카테고리 제안:** 엔터테인먼트 · **초기 배포 지역 제안:** 대한민국

**상세 설명**

```text
추천받은 작품, 구독 중인 OTT에도 있을까요?
AniOTT Switch는 현재 보고 있는 작품을 다른 OTT에서 찾아 연결하고, 작품을 저장·분류해 다시 찾아볼 수 있는 보관함을 제공하는 확장 프로그램입니다.

■ 작품을 찾고 다른 OTT로 이동
지원 OTT의 작품 상세 화면에서 왼쪽 사이드바를 열어 보세요. 제목과 작품 정보를 확인하고, 다른 서비스의 같은 작품 페이지로 이동할 수 있습니다. 검색 결과가 여러 개이거나 같은 작품인지 확신할 수 없으면 직접 검색해서 선택할 수 있습니다. 본편 재생 중에는 사이드바를 숨깁니다.

■ 작품 중심의 보관함
관심 있는 작품을 카테고리별로 모으고 즐겨찾기로 표시하세요. 대표 이미지와 소개를 함께 보면서 제목, 별칭, 설명, 메모와 OTT 연결을 편집할 수 있습니다. 구독 서비스를 선택해 관련 작품을 골라볼 수 있습니다.

■ 내보내기와 가져오기
전체 보관함을 JSON 파일로 백업하거나 선택한 카테고리를 내보낼 수 있습니다. 그룹 공유에는 개인 메모, 즐겨찾기와 구독 설정을 제외합니다. 검색 결과 초기화로 저장된 자동 검색 연결을 지우고 다시 확인할 수도 있습니다.

■ 데이터 처리 안내
지원 OTT의 현재 작품 URL, 제목, 소개, 이미지와 검색 결과를 읽어 작품을 식별합니다. 보관함, 카테고리, 메모, 설정과 백업 병합용 설치 식별자는 이 브라우저에 저장합니다. 재생 여부와 임시 확인 탭 상태는 사이드바 표시와 안전한 이동에만 일시적으로 사용합니다.
사이드바를 열거나 OTT 조회를 실행하면 작품 제목·별칭이 해당 OTT에 전달됩니다. 필요한 경우 기존 로그인 세션을 사용하는 임시 확인 탭이 열릴 수 있으며, 포스터를 표시하면 이미지 제공자에게 요청이 발생합니다. 개발자 서버 전송, 광고 분석과 로그인 쿠키·비밀번호 읽기 기능은 없습니다.

작품 페이지를 찾았더라도 구독에 포함되거나 한국에서 바로 재생할 수 있음을 보장하지는 않습니다. 구독, 로그인, 제공 지역, 자막·더빙, 시즌, 대여·구매 조건은 해당 OTT에서 확인해 주세요. AniOTT Switch는 각 OTT가 제공하거나 후원하는 공식 확장 프로그램이 아닙니다.

개인정보처리방침: https://github.com/pnpcrow/animation-ott-switch/blob/main/docs/privacy.md
사용 안내 및 소스: https://github.com/pnpcrow/animation-ott-switch
문의: https://github.com/pnpcrow/animation-ott-switch/issues
```

상세 설명에는 현재 제공하지 않는 Google Drive 동기화·WebLLM·AI 자동 판단을 기능으로 기재하지 않습니다. [공식 등록정보 안내](https://developer.chrome.com/docs/webstore/cws-dashboard-listing)는 실제 기능을 명확히 설명하고 키워드 반복을 피하도록 안내합니다.

## 개인정보 보호 탭 — 단일 목적

```text
사용자가 보고 있는 OTT 작품을 다른 지원 OTT의 동일 작품 페이지와 연결하고, 그 작품을 개인 보관함에 저장·분류하여 다시 찾아볼 수 있게 하는 것이 단일 목적입니다. 작품 정보 추출, 동일 작품 검색·이동, 카테고리와 메모 관리, JSON 내보내기·가져오기는 이 작품 중심 연결·보관 기능을 제공합니다.
```

## 개인정보 보호 탭 — 권한 사용 근거

### storage

**0.1.7 제출 패키지에서는 이 권한을 제거했습니다. 사용 근거를 입력할 대상이 아닙니다.** 보관함은 IndexedDB에 저장하며 `chrome.storage` API를 사용하지 않습니다. 이전 0.1.6 패키지가 선택되어 있어 입력란이 남아 있다면 새 ZIP 업로드 후 권한 목록을 다시 확인합니다.

이전 코드는 비어 있는 `chrome.storage.local`의 접근 수준만 설정했고, 실제 북마크 저장은 IndexedDB가 담당했습니다. 따라서 “북마크 저장에 storage 권한이 필요하다”는 문구를 작성하지 않습니다. 기능에 필요하지 않은 권한은 제거하라는 [공식 최소 권한 안내](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy#list_and_justify_any_permissions)에 따랐습니다.

### 호스트 권한

```text
지원 OTT의 작품 상세·모달·검색 화면에서 제목, 소개, 대표 이미지 URL과 작품 링크를 읽어 현재 작품을 식별하고 사이드바와 북마크 기능을 제공합니다. 다른 OTT의 공식 검색·상세 응답 또는 임시 확인 탭에서 같은 작품인지 검증하여 직접 이동할 주소를 찾습니다. 접근은 라프텔, 애니플러스, 크런치롤, 넷플릭스, 프라임비디오, Apple TV, 웨이브, 티빙, 쿠팡플레이, 왓챠의 지정 HTTPS 도메인과 라프텔 공개 검색 API로 한정합니다. 각 서비스의 www/비-www 주소와 작품 상세 모달·검색·재생 경로를 처리해야 하므로 해당 도메인의 경로 범위를 사용합니다. api.laftel.net은 제목으로 공개 작품 검색 결과를 확인하는 데 필요합니다. 사용자가 사이트를 이동한 뒤에도 상세 화면을 인식해야 하고 여러 공식 서비스의 결과를 확인해야 하므로 일시적인 현재 탭 접근만으로는 기능을 제공할 수 없습니다. 계정 비밀번호나 쿠키·토큰 값, 브라우저 전체 방문 기록은 읽지 않습니다.
```

호스트별 근거와 코드 위치는 [데이터 처리 근거표](privacy-data-map.md)에 있습니다. 공개 HTTP 요청은 인증정보를 제외하며, 임시 탭 탐색에서는 브라우저가 기존 세션을 사용할 수 있음을 개인정보처리방침에 별도로 밝힙니다.

### 원격 코드

**“아니요, 원격 코드를 사용하지 않습니다”**를 선택합니다.

```text
실행하는 JavaScript와 CSS는 제출한 확장 패키지에 포함되어 있습니다. 공식 OTT에서 받은 HTML/JSON은 작품 정보와 URL을 확인하는 데이터로 해석하며 외부 스크립트를 실행하지 않습니다. 설치용 확장은 원격 모델·WebLLM 런타임·CDN JavaScript를 다운로드하거나 실행하지 않습니다. 저장소의 eval 디렉터리는 개발 평가 도구이고 제출 패키지에 포함되지 않습니다.
```

공식 OTT를 일반 웹 탭에서 여는 것과 확장 코드 자체를 원격에서 내려받아 실행하는 것은 구분합니다. [공식 원격 코드 입력 안내](https://developer.chrome.com/docs/webstore/cws-dashboard-privacy#declare_any_remote_code)를 기준으로 합니다.

- 사용자 데이터를 허용된 경우 외에 제3자에게 판매·이전하지 않습니다. 공식 OTT 조회와 사용자가 선택한 내보내기는 공개한 핵심 기능의 범위입니다.
