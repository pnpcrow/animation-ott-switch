# 0.1.2 · 검색어의 Watch 재유입 수정

2026-11-13 · 비공개 알파

이전 수정에서 직접 검색 링크가 제목 정제를 건너뛰고, JSON-LD의 `Watch`가 붙은 제목이 정상 화면 제목보다 우선되는 경로가 남아 있었습니다. 원본을 다시 읽을 때 Crunchyroll의 홈페이지 홍보 문구가 작품명을 대체하는 문제도 수정했습니다.

- 자동 검색·직접 검색·보관함 검색에 같은 제목 정제를 적용합니다. 구버전 북마크의 한국어 제목 앞 `Watch`는 원본 요청 실패 시에도 정리하며, `Watch Dogs` 같은 실제 제목은 보존합니다.
- 화면 제목과 JSON-LD를 대조하고 홈페이지 홍보 문구를 제목·별칭에서 제외합니다. 원본 재확인의 결과가 다른 작품명이면 기존 검색어를 바꾸지 않습니다.
- 저장된 사용자 지정 표시 제목·이미지·설명은 변경하지 않습니다.

단위 테스트 229개와 브라우저 회귀 테스트 17개가 통과했습니다. 실제 검색 구현에 `Watch`가 붙은 한국어 제목과 Crunchyroll 홍보 문구 별칭을 입력해 라프텔 공개 API를 조회했고, `어느 마녀가 죽을 때까지`의 작품 주소 `https://laftel.net/item/42783`으로 연결 가능한 결과를 확인했습니다. Crunchyroll 로그인 환경 전체의 호환성을 확인한 것은 아닙니다. GitHub Actions는 기존 계정 예산 제한으로 실행되지 않았습니다.

`ott-switch-0.1.2.zip`을 풀어 기존에 로드한 폴더의 파일을 교체한 뒤 `chrome://extensions`에서 확장을 새로고침하세요. 열려 있는 OTT 페이지도 새로고침해야 새 코드가 적용됩니다. 보관함을 유지하려면 확장을 제거하지 마세요.
