# AniOTT Switch 개인정보처리방침

시행일: 2026년 11월 14일 · 적용 버전: 0.1.7

AniOTT Switch는 보고 있는 작품을 다른 OTT에서 찾아 이동하고, 작품별 보관함을 관리하는 Chrome 확장 프로그램입니다. 개발자는 GitHub 계정 [pnpcrow](https://github.com/pnpcrow)입니다. 이 방침은 설치용 확장 프로그램에 적용됩니다.

작품 정보와 설정은 사용 중인 Chrome 프로필 안에 저장합니다. 개발자 서버로 보관함이나 사용 기록을 보내지 않으며, 광고·사용 분석 도구를 포함하지 않습니다. 다만 **OTT 조회를 실행하면 작품 제목·별칭이 조회 대상 서비스에 전달되고, 포스터를 표시하면 이미지 제공자에게 요청이 발생합니다.** 따라서 모든 처리가 기기 안에서만 끝나는 것은 아닙니다.

## 외부 요청과 전달 대상

사이드바를 열거나 보관함의 OTT 조회를 실행하면 정리한 작품 제목·별칭으로 지원 OTT를 조회합니다. 원래 작품 제목을 확인하기 위해 해당 공식 상세 페이지를 다시 읽을 수도 있습니다. 검색 캐시와 이미 저장한 연결을 활용하며, 직접 검색·찾아서 이동·스위치 기능은 선택한 공식 서비스의 페이지를 엽니다.

조회 대상은 라프텔(`laftel.net`, `api.laftel.net`), 애니플러스(`aniplustv.com`), 크런치롤(`crunchyroll.com`), 넷플릭스(`netflix.com`), 프라임비디오(`primevideo.com`), Apple TV(`tv.apple.com`), 웨이브(`wavve.com`), 티빙(`tving.com`), 쿠팡플레이(`coupangplay.com`), 왓챠(`watcha.com`)입니다. 각 사이트의 `www` 주소도 포함됩니다.

- 확장이 보내는 공개 검색·상세 HTTP 요청은 HTTPS를 사용하고 `credentials: omit`으로 쿠키 등 계정 인증 정보를 제외합니다. 개발자가 운영하는 중계 서버를 통하지 않습니다.
- 공개 응답만으로 작품을 확인하지 못하면 공식 검색·상세 페이지를 비활성·음소거 임시 탭에서 열 수 있습니다. 자동 조회의 임시 탭 확인은 사용자가 구독 서비스로 선택한 OTT에 한정하며, **찾아서 이동**은 사용자가 선택한 서비스에서 실행합니다. 일반 웹 탐색이므로 브라우저의 기존 로그인 세션이 사용될 수 있습니다. 확장은 쿠키나 토큰 값을 읽지 않고 화면의 작품 정보를 확인합니다.
- 임시 탭은 동시에 최대 2개입니다. 확장이 계속 관리하는 탭은 확인 뒤 닫지만, 사용자가 활성화하거나 다른 페이지로 이동한 탭은 자동으로 닫지 않습니다. 사이트와 브라우저에는 일반 방문 요청·기록이 남을 수 있습니다.
- 대표 이미지는 파일을 보관함 DB에 저장하지 않고 HTTPS URL로 불러옵니다. OTT의 이미지 제공자 또는 사용자가 지정한 이미지 URL의 제공자가 요청을 받습니다. 이미지 요청은 `no-referrer`를 사용합니다. 이미지 캐싱 여부와 기간은 브라우저와 제공자의 응답 정책에 따릅니다.
- 외부 서버는 요청 처리 과정에서 IP 주소, 브라우저 요청 정보, 요청 URL과 검색어 등을 받을 수 있습니다. 각 OTT와 이미지 제공자의 처리는 해당 서비스의 개인정보처리방침을 따릅니다. 확장은 IP 주소나 실제 위치를 별도로 조회·보관하지 않습니다.

개발자는 사용 데이터를 판매하거나 광고·신용평가·대출 심사에 사용하지 않습니다. 작품 연결과 보관함 기능에 필요한 위 요청 이외에 보관함·메모·설치 식별자를 개발자 서버나 분석 서비스로 자동 전송하지 않습니다. **AniOTT Switch의 사용자 데이터 사용은 Chrome 웹 스토어 사용자 데이터 정책의 Limited Use 제한을 따릅니다.**

## 로컬 저장, 백업과 삭제

보관함은 현재 Chrome 프로필의 확장 전용 IndexedDB(`ott-switch-library`)에 저장됩니다. 다른 프로필이나 기기에 자동 공유되지 않습니다. 로컬 저장소와 내보낸 JSON에는 별도의 애플리케이션 암호화를 적용하지 않습니다. 기기·Chrome 프로필·백업 파일에 접근할 수 있는 사람은 저장 정보에 접근할 수 있으므로, 기기와 백업 파일의 접근 권한을 관리해 주세요.

- **조회·수정:** 보관함에서 작품·카테고리·메모·설정을 확인하고 변경할 수 있습니다.
- **작품·카테고리 삭제:** 목록에서는 사라지지만 백업 병합 시 삭제된 항목이 되살아나는 것을 막기 위해 삭제 표시와 기존 레코드를 로컬에 남깁니다. 일반 삭제는 원본 데이터의 즉시 영구 제거가 아닙니다.
- **검색 결과 초기화:** 확장의 검색·제목 재조회 캐시와 자동으로 찾은 북마크 연결을 지웁니다. 저장한 제목·메모·카테고리와 수동 연결은 유지합니다. 사이트 쿠키·로그인·Chrome 전체 캐시는 지우지 않습니다.
- **전체 JSON 백업:** 메모·설정·수정 기록·삭제 표시가 있는 항목까지 포함할 수 있습니다. 사용자가 저장 위치와 전달 대상을 정합니다. 확장이 백업 파일을 자동 업로드하지 않습니다.
- **그룹 내보내기:** 선택한 카테고리와 살아 있는 작품을 포함합니다. 개인 메모·즐겨찾기·구독 설정은 제외하지만 작품·카테고리·연결·수정 기록은 포함할 수 있습니다. 공유 전에 파일 내용을 확인할 수 있습니다.
- **영구 제거:** 확장을 제거하면 해당 Chrome 프로필의 확장 로컬 데이터가 삭제됩니다. 이미 내보낸 파일·사용자가 복사한 파일·OTT 사이트의 기록은 별도로 삭제해야 합니다. 개발자는 사용자의 로컬 저장소에 원격 접근하여 삭제할 수 없습니다.

## 권한과 포함하지 않는 기능

호스트 접근 권한은 위 10개 OTT와 라프텔 검색 API에 한정합니다. 지원 화면의 작품 정보를 읽고 사이드바를 표시하거나 검색 결과·상세 페이지를 검증하는 데 사용합니다. 다른 모든 웹사이트에 접근하는 `<all_urls>` 권한과 `history`, `cookies`, `webRequest`, `tabs` 권한을 요청하지 않습니다. 0.1.7부터 불필요한 `storage` 권한도 제거했습니다. 보관함의 IndexedDB 저장은 그대로 유지됩니다.

현재 설치용 확장에는 Google Drive 연결·계정 인증·클라우드 동기화, AI 모델 다운로드·원격 추론, 원격 JavaScript 실행, 광고·사용 분석 SDK가 없습니다. 저장소의 `eval/` 및 모델 실험 스크립트는 개발 평가 도구이며 설치용 확장에 포함되지 않습니다. 해당 도구를 별도로 실행하는 경우의 입력과 다운로드는 이 확장의 자동 기능이 아닙니다.

## 문의와 변경 안내

기능과 개인정보 처리에 관한 문의는 [AniOTT Switch GitHub Issues](https://github.com/pnpcrow/animation-ott-switch/issues)에서 받습니다. 공개 문의에는 비밀번호, 인증 토큰, 개인 메모가 포함된 전체 백업 파일을 첨부하지 마세요. 사용자가 직접 남긴 문의는 GitHub에서 처리하며 [GitHub 개인정보처리방침](https://docs.github.com/site-policy/privacy-policies/github-general-privacy-statement)이 적용됩니다.

처리 정보나 이용 목적이 바뀌면 이 문서의 시행일·적용 버전과 릴리즈 안내를 갱신합니다. 추가 권한이나 별도 동의가 필요한 새 기능은 그 기능을 도입할 때 안내합니다.
