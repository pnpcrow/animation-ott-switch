# 개인정보 및 권한

OTT Switch 0.1.3은 자체 서버, 분석 도구, 광고 추적, 원격 실행 코드를 포함하지 않습니다. WebLLM은 기본 기능 안정화 이후 선택 기능으로 검토하며 현재 모델 의존성·다운로드·모델 서버 전송은 없습니다.

- **보관**: 저장한 제목·별칭·설명·HTTPS 이미지 URL·OTT 링크·카테고리·메모·즐겨찾기, 구독 서비스 선택, 수정/삭제 시각. Chrome 프로필의 확장 IndexedDB에 저장됩니다.
- **읽기**: 지원 OTT 화면과 검색 결과에 표시된 DOM 제목·링크·이미지·설명, 현재 페이지 주소, 영상 재생 상태. 로그인 쿠키·토큰·영상 URL·재생 기록을 수집하지 않습니다.
- **공개 요청**: 오버레이를 열거나 OTT 다시 찾기를 실행하면 정제된 작품 제목/별칭이 공식 OTT 검색에 전송됩니다. 필요하면 원본 작품의 공식 상세 주소를 다시 읽어 제목 근거를 확인합니다. 홈페이지 홍보 문구나 관계없는 제목은 검색어로 받아들이지 않으며, 검색용 정제가 사용자가 저장한 표시 제목·설명을 덮어쓰지는 않습니다. 서비스 워커의 공개 HTTP 요청은 `credentials: omit`으로 계정 인증 정보를 제외합니다.
- **브라우저 확인**: 공개 요청만으로 확인하지 못하면 공식 검색·상세 화면을 비활성·음소거 임시 탭에서 열 수 있습니다. 일반 브라우저 탐색이므로 해당 사이트의 기존 로그인 세션이 사용될 수 있고, 사이트는 통상적인 방문 요청을 받습니다. 확장 기능은 쿠키·토큰 API를 읽지 않고 렌더링된 작품 정보만 확인합니다. 자동 확인은 구독한 서비스에 한정하고, **찾아서 이동**은 선택한 서비스에서 실행합니다. 동시 임시 탭은 최대 2개입니다. 작업 후 자신이 관리하는 탭은 닫지만 사용자가 활성화하거나 다른 페이지로 이동한 탭은 남겨 둡니다.
- **직접 이동**: 직접 검색과 검증된 작품 스위치 링크는 해당 서비스가 처리합니다.
- **주소 없는 검색 카드**: 웨이브에서는 관리 중인 숨겨진 임시 탭에서 제목이 일치하는 프로그램·영화 카드를 정상 클릭하여 작품 주소를 확인할 수 있습니다. 클릭 직전에 현재 카드가 같은지 확인하며 여러 후보·에피소드·추천 카드는 자동 선택하지 않습니다. 이동한 공식 상세 정보까지 검증하고 사용자가 선택한 탭은 조작하지 않습니다.
- **검색창 표시**: Prime Video의 공식 검색 폼이 비어 있으면 URL에 이미 전달한 검색어를 한 번 표시합니다. 폼 자동 제출·포커스 이동을 하지 않고 사용자의 입력·삭제를 덮어쓰지 않습니다.
- **검색 캐시 초기화**: 확장 내부 검색 결과·원본 제목 재조회 캐시와 북마크의 자동 검색 연결을 지웁니다. 수동·현재 페이지 링크와 저장한 제목·설명·이미지·카테고리·메모는 유지합니다. 사이트 쿠키·로그인과 브라우저 전체 캐시는 삭제하지 않습니다. 공개 재조회는 `cache: no-store`로 실행합니다.
- **이미지**: 원본 이미지 제공자는 일반 HTTP 요청 정보를 받을 수 있습니다. 이미지 요청은 referrer를 보내지 않습니다. DB와 JSON에는 이미지 URL만 들어갑니다.
- **백업**: 전체 JSON은 개인 메모·설정과 삭제 항목의 데이터도 포함합니다. 그룹 공유는 살아 있는 해당 작품과 카테고리만 포함하며 개인 메모·즐겨찾기·구독 설정을 제외합니다.
- **Drive**: 현재 버전에는 Google 계정 연결이나 업로드가 없습니다.

호스트 권한은 지정한 10개 OTT와 라프텔 검색 API에 한정합니다. `tabs`, `history`, `cookies`, `webRequest`, `<all_urls>` 권한은 요청하지 않습니다. `storage`는 확장 저장 접근 경계 설정에 사용합니다.

확장 제거 시 로컬 데이터가 삭제됩니다. 내보낸 파일은 사용자가 관리합니다. 최신 수정 병합을 위해 삭제 기록을 유지하므로 일반 작품 삭제와 전체 데이터 영구 제거는 다릅니다.
