# 구조와 데이터 수명

## 실행 경계

콘텐츠 스크립트는 공개된 DOM에서 작품 메타데이터를 추출하고 Shadow DOM 안에 오버레이를 렌더링한다. 서비스 워커가 허용된 OTT만 조회하고 IndexedDB의 변경을 처리한다. 확장 내부 보관함은 같은 메시지 API를 사용한다. 서비스 워커는 DOM API를 가정하지 않는다. 네트워크 실패는 작품 부재의 근거가 아니다.

## 동일 작품

플랫폼의 정규 작품 URL/ID가 가장 강한 키다. 다른 플랫폼 간 제목 비교에서는 유니코드·공백·기호를 정규화하되 시즌, 파트, 연도 차이를 지우지 않는다. 후보가 여럿이거나 정보가 부족하면 직접 확인을 요구한다. 사용자는 연결 URL을 편집할 수 있다. 지역별 제공 여부 및 구매/대여 여부는 실제 서비스에서 최종 확인한다.

`Watch`와 서비스명 같은 페이지 장식은 구조화된 제목·로고·메타데이터의 출처를 비교해 제거한다. 실제 작품명의 `Watch`는 일괄 삭제하지 않는다. 라프텔의 `/item/{ID}`와 `?modal={ID}`, Netflix의 `/title/{ID}`와 `?jbv={ID}`는 같은 작품 ID로 묶는다. 모달에서는 현재 보이는 모달 내부 정보만 읽고 배경 페이지의 오래된 메타데이터를 섞지 않는다. 같은 작품의 모달 내부 이동에서는 펼친 사이드바 상태를 유지한다.

## 검색과 직접 이동

먼저 제한된 공개 HTTP 요청으로 공식 검색 후보를 수집한다. 확인할 수 없는 경우 `rendered-search`가 일반 브라우저 임시 탭을 사용해 자바스크립트로 표시된 검색 결과를 읽는다. 자동 조회는 구독 서비스만 이 경로를 사용하고 명시적인 **찾아서 이동**은 선택한 서비스에서 실행한다. 동시 실행은 최대 2개, 검색은 14초, 상세 확인은 10초로 제한한다. 로딩 중인 결과는 완료된 검색으로 간주하지 않으며 일정 시간 안정된 DOM을 기다린다.

라프텔 공개 카탈로그 API는 응답의 공식 제목·작품 ID·제공 상태로 직접 판정한다. 이 경로는 별도의 상세 페이지 방문을 요구하지 않는다. 그 외 공개 HTML 후보와 브라우저 DOM 후보는 상세 메타데이터로 다시 검증한다.

콘텐츠 스크립트의 `probe`는 확장 내부 요청에 대해서만 DOM 결과를 반환한다. 서비스 워커는 요청 토큰·서비스·현재 URL을 대조하고, 정확한 제목/별칭과 연도를 비교한다. 검색 후보를 고른 뒤 해당 상세 페이지의 제목과 작품 ID를 다시 확인한다. 여러 후보는 자동 선택하지 않고, 사용자가 선택해도 상세 검증을 거친다. 상태는 서비스별로 순차 표시되며 오래된 요청이 새 선택을 덮어쓰지 않도록 요청 세대를 구분한다.

임시 탭은 비활성·음소거로 만들며 기존 사이트 세션을 자연스럽게 사용한다. 쿠키·토큰을 읽거나 인증을 우회하지 않는다. 사용자가 활성화한 탭 또는 예상하지 않은 주소로 이동한 탭은 관리 대상에서 제외하여 자동 탐색·종료하지 않는다. 원래 탭에서 다른 페이지로 이동했다면 그 탭을 뒤늦게 스위치하지 않는다.

## 미리보기와 본편 재생

자동 미리보기 영상이 재생된다는 이유만으로 오버레이를 숨기지 않는다. 실제 재생 라우트, 영상 컨트롤, 본편 플레이어의 탐색 컨트롤 등과 보이는 영상의 재생 상태를 함께 확인한다. 전체화면과 Picture-in-Picture에서는 숨긴다. 사이트의 플레이어 DOM 변경 및 다른 도메인의 iframe은 별도 QA 대상이다.

## 저장과 동기화

북마크, 카테고리, 설정은 독립적인 수정 기록(`updatedAt`, `deviceId`)을 가진다. 같은 ID의 충돌은 최신 수정 우선, 동일 시각은 device ID와 결정적 비교로 해소한다. 삭제도 tombstone으로 보존하여 오래된 백업에서 항목이 부활하지 않는다. 카테고리 삭제는 북마크를 삭제하지 않는다. 전체 백업은 삭제 기록을 포함하고 그룹 공유는 선택한 카테고리의 살아 있는 작품만 포함한다. 잘못된 파일은 원자적으로 거부한다.

Google Drive는 선택적 후속 단계다. `drive.appdata` 최소 범위로 앱 전용 JSON을 저장하고, 읽기→검증→병합→조건부 쓰기 및 충돌 시 재읽기를 수행해야 한다. OAuth 클라이언트와 고정 확장 ID가 준비되기 전에는 연결된 것처럼 표시하지 않는다. 기기 시계 오차의 영향과 tombstone 정리 정책은 실서비스 도입 전에 별도로 검증한다.

## 이미지

데이터베이스와 내보내기에는 HTTPS URL만 저장한다. 첫 렌더링부터 브라우저 HTTP 캐시를 활용한다. CORS를 우회해 이미지 바이트를 수집하거나 무기한 저장하지 않는다. URL 만료/차단 시 대체 화면을 제공한다.
