# OTT 지원 및 확인 범위

확인일: 2026-11-13, 한국 환경. 지원 목록과 **자동 검색으로 확인 가능한 범위**는 다릅니다. 로그인·지역·연령·구독 등급에 따른 재생 권한은 확장 기능이 판정하지 않습니다. 사이트가 페이지를 제공해도 구독에 포함되지 않거나 서비스가 종료됐을 수 있습니다.

## 판정 규칙

- **작품 페이지 확인**: 정확한 정규화 제목 또는 사용자가 추가한 별칭이 일치하고 유효한 공식 작품 URL이 확인된 경우. 검색 HTML·렌더링 DOM 후보는 상세 메타데이터를 다시 읽습니다. 양쪽 연도가 있으면 같은 연도여야 합니다. 같은 작품의 단독·모달 주소는 같은 ID로 중복 제거합니다.
- **동일 작품 확인 필요**: 같은 제목의 여러 URL이 남는 경우. 자막과 더빙판을 임의로 선택하지 않습니다.
- **검색 결과 없음**: 전체 응답으로 동일 제목을 찾지 못했거나 만료/시청 불가가 명시된 경우. 이 검색어로 찾지 못했다는 뜻이며 모든 언어의 전 세계 카탈로그 부재를 뜻하지 않습니다.
- **확인 필요**: 로그인, 403, 타임아웃, 불완전 검색, HTML 구조 변경, 상세 페이지 불일치. 확인된 직접 링크가 없으며 **찾아서 이동**으로 브라우저 검증을 시도하거나 공식 검색을 열 수 있습니다. 검증 실패 시 작품 페이지로 자동 이동하지 않습니다.

라프텔 공개 카탈로그 API 결과는 공식 제목·작품 ID·제공 상태를 근거로 직접 판정하므로 이 경로는 상세 페이지를 별도로 다시 방문하지 않습니다. 라프텔의 `is_viewing`은 현재 공식 프런트엔드에서 `isViewable`로 사용하며, false일 때 작품 권리 요청 UI를 제공합니다. 사용자 개인의 시청 완료나 구매 여부로 해석하지 않습니다. `is_viewing: true`이지만 `is_episode_existed: false`인 공개 예정 작품은 확인 필요로 표시합니다.

시즌·파트·숫자·극장판 표시는 지우지 않습니다. `(자막)`·`(더빙)`과 서비스명 접미사는 표시용 장식으로 정규화합니다. `Watch`는 메타데이터 출처와 제목 근거를 비교해 시청 안내인 경우만 제거합니다. 다른 언어의 제목은 추측 번역하지 않으며 보관함 별칭으로 추가할 수 있습니다. 같은 제목의 리메이크인데 연도 데이터가 없는 경우를 자동으로 완전히 구분할 수는 없습니다. 후보 연결 전 작품 소개와 시즌을 확인하는 절차가 필요합니다.

공개 HTTP 검색은 `credentials: omit`으로 요청하며 응답을 4 MB와 요청당 8초, 최대 3개 제목/별칭으로 제한합니다. 공개 요청만으로 판정할 수 없으면 비활성·음소거 임시 탭에서 실제 표시된 검색 결과와 상세 제목을 확인합니다. 자동 조회는 구독 서비스만 이 경로를 사용하고 **찾아서 이동**은 선택한 서비스에서 실행합니다. 동시 임시 탭은 최대 2개, 검색은 14초, 상세 확인은 10초이며 최대 2개 제목/별칭을 확인합니다. 사용자가 활성화한 탭은 자동 이동·종료하지 않습니다.

웨이브의 URL 없는 카드는 제목이 일치하는 프로그램·영화 후보가 하나일 때만 클릭합니다. 클릭 직전에 카드와 검색 화면이 바뀌지 않았는지 다시 검사하며 에피소드·에디터 추천·동명 중복은 자동으로 선택하지 않습니다. 클릭으로 얻은 주소도 공식 작품 URL이어야 하고 상세 제목 검증을 통과해야 합니다. 현재 공개 작품 화면에서는 로고 제목·대표 이미지·전체 소개를 사용하고 시즌 진입을 유지합니다.

설정·사이드바의 검색 캐시 초기화는 확장의 임시 결과와 원본 제목 재조회 캐시, `source: search` 자동 저장 링크를 비웁니다. 수동·현재 페이지 링크와 북마크 표시 정보는 유지하며 사이트 쿠키·로그인을 삭제하지 않습니다. 기본 검색은 WebLLM 없이 동작하며 선택형 모델 평가 도구는 확장과 분리합니다.

0.1.4의 [8작품 교차 검사](cross-check-2026-11-13.md)에서는 애니플러스의 URL 없는 카드·상세 레이어, 티빙의 포스터 문구·회차 제목을 보완했습니다. 니아·Re:제로 감독판의 애니플러스 이동, 어느 마녀·Re:제로 감독판의 티빙 이동과 역방향 일부를 실제 확인했습니다. 자막·더빙 중복은 보류하거나 후보를 선택해 검증하며, Apple 검색에서 누락된 작품을 전체 카탈로그 부재로 단정하지 않습니다. 애니플러스 상세가 다른 서비스의 시청 링크를 안내할 수도 있습니다.

임시 탭은 일반 브라우저 탐색이므로 사이트의 기존 로그인 세션을 사용할 수 있습니다. 확장 기능이 쿠키, 로그인 토큰, DRM, 영상 URL, 비공개 재생 API를 수집하거나 우회하지는 않습니다. 로그인이나 접근 확인이 필요하면 결과를 `확인 필요`로 남깁니다. 사이트 구조가 바뀌어도 확인 필요로 돌아갑니다. 이미지 URL만 저장하며 원본 이미지의 장기 보존을 보장하지 않습니다.

## 지역 및 다음 후보

Crunchyroll은 [공식 지역 제한 안내](https://help.crunchyroll.com/hc/en-us/articles/43269213267092-Why-can-t-I-watch-certain-shows-in-my-region)에서 작품별 국가 판권 차이를 명시합니다. 한국어 화면이나 검색 엔진의 작품 노출만으로 한국 정식 시청을 확정하지 않습니다. 이 구현은 지역 우회 기능을 제공하지 않습니다.

추가 후보는 디즈니+입니다. [한국 공식 아니메 카탈로그](https://www.disneyplus.com/ko-kr/browse/page-00ef9b51-0ed0-4883-b1e4-fd5a075c7f54)가 있어 애니메이션 범위 확장에 적합하지만, 이번 10개 서비스 범위에는 포함하지 않았습니다.

## 검증 근거

`tests/fixtures/providers/`에는 2026-11-13 공식 공개 응답에서 필요한 메타데이터만 남긴 Laftel·Netflix·TVING 상세 HTML, Apple TV 검색 카드 속성, Laftel 검색 JSON이 있습니다. 설명은 120자로 잘랐고 인증 데이터·실행 스크립트·영상 데이터는 저장하지 않았습니다. 네트워크를 쓰지 않는 회귀 테스트는 차단/타임아웃/불완전 응답, 버전 중복, 연도 불일치, SPA 이전 페이지 메타데이터, 안전한 URL 검사를 포함합니다.

대표 확인 URL:

- [라프텔 프리렌](https://laftel.net/item/41666)
- [Netflix 프리렌](https://www.netflix.com/kr/title/81726714)
- [Apple TV 한국 스누피 검색](https://tv.apple.com/kr/search?term=더%20스누피%20쇼)
- [티빙 공개 작품](https://www.tving.com/contents/M000359644)
- [애니플러스 공식 웹 앱](https://www.aniplustv.com/)
- [웨이브 공식 웹 앱](https://www.wavve.com/)
- [웨이브 어느 마녀가 죽을 때까지](https://www.wavve.com/player/vod?programid=CF02_CF0000000119&landing=season)
- [왓챠 공식 OpenSearch 설명](https://watcha.com/opensearch.xml)

0.1.1에서는 실제 공개 라프텔 검색의 `?modal=41666`과 `#item-modal`을 열어 제목·대표 이미지·소개 및 자동 미리보기 중 사이드바 유지를 확인했습니다. Netflix 모달·단독 페이지와 Prime Video 미리보기 전환은 재현 DOM을 이용한 확장 브라우저 테스트로 검증했습니다. 브라우저 검색의 일치·상세 불일치·후보 선택·사용자 활성화 탭 보존도 같은 방식으로 검사합니다.

0.1.3에서는 실제 확장이 공개 웨이브 검색 카드의 정상 클릭을 실행하고 `programid=CF02_CF0000000119&landing=season`의 상세 제목·이미지·소개를 읽은 후 최종 탭을 여는 것을 확인했습니다. Prime Video에서는 공식 `phrase` 검색 URL이 결과를 조회하지만 전체 이동 후 상단 입력창이 비어 있는 동작을 확인했습니다. 빈 검색창 표시·사용자 편집 보존, 상세 불일치·중복 웨이브 후보 보류, 캐시 초기화는 회귀 테스트로 검사합니다.

실제 로그인 계정이 필요한 각 서비스의 모달·연령 제한·한국 재생 권한과 구독 상품별 차이는 수동 QA 목록에 남겨 둡니다. Prime Video 커스텀 본편 플레이어의 실제 계정별 컨트롤도 추가 확인 대상입니다. 이 문서의 실측 성공은 전체 카탈로그 및 모든 계정 상태의 호환성을 의미하지 않습니다.
