# OTT 지원 및 확인 범위

확인일: 2026-11-13, 한국 환경. 지원 목록과 **자동 검색으로 확인 가능한 범위**는 다릅니다. 로그인·지역·연령·구독 등급에 따른 재생 권한은 확장 기능이 판정하지 않습니다. 사이트가 페이지를 제공해도 구독에 포함되지 않거나 서비스가 종료됐을 수 있습니다.

| 서비스 | 인식하는 작품 URL | 자동 검색과 현재 확인 결과 |
| --- | --- | --- |
| 라프텔 | `/item/{숫자}` | 공식 사이트가 사용하는 익명 검색 API `/api/search/v3/keyword/`의 제목, 만료, 시청 가능 플래그. 프리렌 검색과 상세 메타데이터 실측 성공. 자막·더빙 중복은 선택 필요로 분리. |
| 애니플러스 | `/items/{숫자}` | 공식 현재 웹 앱 라우트 확인. `/Search?st=제목` 검색은 브라우저 렌더링 의존. 서버 HTML이 빈 셸이면 확인 필요. 로그인 화면의 실제 제목 추출은 추가 현장 QA 대상. |
| Crunchyroll | `/{언어}/series/{ID}/{slug}` 또는 `/series/{ID}` | 공식 검색 HTML과 상세 페이지 메타데이터를 이용. 실측 익명 요청은 403 접근 확인으로 확인 필요. 한국 재생 가능 여부를 단정하지 않음. |
| Netflix | `/{국가}/title/{ID}`, `/title/{ID}`, `/browse?jbv={ID}` | 공개 상세 페이지 및 로그인 후 모달 DOM 추출. 익명 검색은 로그인으로 이동하므로 확인 필요. 프리렌 공개 상세 추출 실측 성공. |
| Prime Video | `/detail/{ID}`, `/-/{언어}/detail/{ID}` | 공개 검색 HTML에서 제목 후보를 찾은 뒤 상세 페이지 재확인. 구독·채널·대여/구매 및 한국 판권은 별도 확인 필요. |
| Apple TV | `/{국가}/show/.../umc.cmc.*`, `/{국가}/movie/.../umc.cmc.*` | 한국 공개 검색 카드 및 상세 메타데이터 재확인. '더 스누피 쇼' 실제 자동 연결 성공. Apple TV 카탈로그 링크는 Apple TV 구독 포함의 보증이 아님. |
| 웨이브 | `/player/vod?contentid=...`, `/player/movie?movieid=...` (`.html` 별칭 포함) | 상세와 재생 화면이 같은 라우트. 실제 영상 재생 중 숨김. 검색은 클라이언트 렌더링 의존으로 확인 필요가 일반적. 로그인 DOM 추가 QA 대상. |
| 티빙 | `/contents/{ID}` | 공개 상세 메타데이터 실측 성공. 검색 HTML에 후보가 있으면 상세 재검증; 빈 셸이면 확인 필요. |
| 쿠팡플레이 | `/content/{UUID}` | 공식 공개 작품 URL 확인. 익명 요청이 지원 브라우저 안내로 이동한 환경에서는 확인 필요. 로그인 DOM 추가 QA 대상. |
| 왓챠 | `/{언어}/contents/{ID}` 또는 `/contents/{ID}` | 왓챠피디아와 구분. 공식 OpenSearch의 `/search?query=제목` 이용. 검색이 클라이언트 렌더링되는 환경은 확인 필요. 로그인 DOM 추가 QA 대상. |

## 판정 규칙

- **작품 페이지 확인**: 정확한 정규화 제목 또는 사용자가 추가한 별칭이 일치하고 유효한 공식 작품 URL이 확인된 경우. 검색 HTML 후보는 상세 메타데이터를 다시 읽습니다. 양쪽 연도가 있으면 같은 연도여야 합니다.
- **동일 작품 확인 필요**: 같은 제목의 여러 URL이 남는 경우. 자막과 더빙판을 임의로 선택하지 않습니다.
- **검색 결과 없음**: 전체 응답으로 동일 제목을 찾지 못했거나 만료/시청 불가가 명시된 경우. 이 검색어로 찾지 못했다는 뜻이며 모든 언어의 전 세계 카탈로그 부재를 뜻하지 않습니다.
- **확인 필요**: 로그인, 403, 타임아웃, 불완전 검색, HTML 구조 변경, 상세 페이지 불일치. 스위치 버튼은 비활성이고 공식 검색 링크가 제공됩니다.

라프텔의 `is_viewing`은 현재 공식 프런트엔드에서 `isViewable`로 사용하며, false일 때 작품 권리 요청 UI를 제공합니다. 사용자 개인의 시청 완료나 구매 여부로 해석하지 않습니다. `is_viewing: true`이지만 `is_episode_existed: false`인 공개 예정 작품은 확인 필요로 표시합니다.

시즌·파트·숫자·극장판 표시는 지우지 않습니다. `(자막)`·`(더빙)`과 서비스명 접미사는 표시용 장식으로 정규화합니다. 다른 언어의 제목은 추측 번역하지 않으며 보관함 별칭으로 추가할 수 있습니다. 같은 제목의 리메이크인데 연도 데이터가 없는 경우를 자동으로 완전히 구분할 수는 없습니다. 후보 연결 전 작품 소개와 시즌을 확인하는 절차가 필요합니다.

현재 검색은 익명 공개 요청만 수행합니다(`credentials: omit`). 쿠키, 로그인 토큰, DRM, 영상 URL, 비공개 재생 API를 수집하거나 우회하지 않습니다. 공식 검색 주소만 생성하고, 응답을 4 MB와 요청당 8초로 제한합니다. 최대 3개 제목/별칭을 조회합니다. 사이트 제공 페이지의 구조가 바뀌면 확인 필요로 돌아갑니다. 이미지 URL만 저장하며 원본 이미지의 장기 보존을 보장하지 않습니다.

## 지역 및 다음 후보

Crunchyroll은 [공식 지역 제한 안내](https://help.crunchyroll.com/hc/en-us/articles/43269213267092-Why-can-t-I-watch-certain-shows-in-my-region)에서 작품별 국가 판권 차이를 명시합니다. 한국어 화면이나 검색 엔진의 작품 노출만으로 한국 정식 시청을 확정하지 않습니다. 이 구현은 지역 우회 기능을 제공하지 않습니다.

추가 후보는 디즈니+입니다. [한국 공식 아니메 카탈로그](https://www.disneyplus.com/ko-kr/browse/page-00ef9b51-0ed0-4883-b1e4-fd5a075c7f54)가 있어 애니메이션 범위 확장에 적합하지만, 이번 10개 서비스 범위에는 포함하지 않았습니다.
