# OTT Switch 0.1.5 · 성능 검사 결과

작성일: 2026-11-14 (한국 시간). 기존에 완료한 측정을 정리한 테스트 릴리즈용 보고서다. 새로 성능 실험을 실행하거나 이전 정답을 바꾸지 않았다.

**현재 릴리즈에 적용한 국소 DOM 수집기와, 제품에 넣지 않은 과거 학습 모델을 구분한다.** 국소 수집기는 실제 공개 DOM 재생 3화면에서 필드 후보 9개 중 8개를 회수했다. 작품 영역을 지정한 경우 필드별 p50은 0.30–1.60ms였다. 이는 모델 추론 시간, 페이지 로딩 시간, OTT 간 전환 완료 시간이 아니다.

## 2. 공개 OTT DOM 재생 — 후보 수집과 처리 시간

기존 개발용 공개 HTML을 브라우저의 분리 문서(DOMParser)로 읽었다. 스크립트·이벤트·프레임·외부 스타일시트를 제거하고 네트워크를 차단했다. 실제 OTT CSS, SPA 실행, 로그인 상태, 네트워크 지연과 실제 표시 크기는 재현하지 않는다. 기존 정답과 HTML은 수정하지 않았다.

각 필드는 5회 워밍업 후 20회 측정했다. 아래는 기존 어댑터가 작품 범위를 지정한 조건이다. 제목·이미지는 허용된 기존 정답 값과 비교하고, 설명은 과거 수집 길이 제한 때문에 접두어 일치로 판정했다. p50은 중앙값, p95는 측정값의 95백분위수다.

## 3. 합성 브라우저 검사 — 입력 크기와 점진 수집

격리 headless Chromium 158.0.8127.18, 화면 1280×900에서 수작업 화면 6개를 검사했다. 필드당 10회 워밍업 후 50회 측정했고 자동 범위 발견을 포함한다. 1ms 미만 수치는 타이머 해상도 영향을 받으며 0.00ms는 작업량이 없다는 뜻이 아니다.

| 합성 화면                | 전체 HTML (B) | 3필드 JSON 합계 (B) | 필드별 p50 범위 (ms) | 필드별 p95 범위 (ms) | 최대 방문 |
| ------------------------ | ------------- | ------------------- | -------------------- | -------------------- | --------- |
| 배경 카드 뒤의 활성 모달 | 58,414        | 2,714               | 0.10–0.10            | 0.20–0.20            | 13        |
| 단독 상세                | 704           | 3,530               | 0.00–0.10            | 0.10–0.20            | 19        |
| 서로 다른 작품 경쟁      | 486           | 3,318               | 0.00–0.10            | 0.10–0.20            | 19        |
| 툴팁·일반 본문 혼동      | 732           | 2,960               | 0.00–0.10            | 0.10–0.20            | 18        |
| 작은 OTT 로고            | 601           | 2,666               | 0.00–0.10            | 0.10–0.10            | 13        |
| 숨겨진 모달              | 675           | 2,666               | 0.00–0.00            | 0.10–0.20            | 11        |

전체 HTML과 3필드 JSON은 **직렬화 크기** 비교다. 이전 제품 추출기가 모델에 전달하던 입력과 직접 비교한 실험이 아니며, 작은 화면에서는 구조화된 문맥 때문에 JSON이 오히려 크다. 큰 모달 예시는 58,414B→2,714B로 95.4% 줄었지만 이를 모든 사이트의 절감률로 일반화할 수 없다.

점진 수집에서는 12회 방문 후 첫 제목을 반환했고 전체 스캔은 807회 방문했다. close() 후 추가 후보가 나오지 않음을 확인했다. 첫 후보만으로 다른 후보가 없다고 결론 내리지 않으며, 기본 선택기는 탐색이 끝나고 근거가 하나로 모일 때만 선택한다.

1440×1440 원본 이미지를 Chromium에 실제 로드해 대표 이미지의 표시 크기 720×405를 원본 크기와 구분했고, 23×23 OTT 로고를 제외했다. DOM 교체 후 XPath가 다른 요소를 가리키는 상황도 검사했다. 링크 검사는 리터럴 URL 2개와 목적지 미확인 동작 1개를 구분했고 JS 액션은 실행하지 않았다.

## 4. 과거 학습 모델 실험 — 이번 릴리즈에는 미적용

아래는 별도 동결된 eval/dom-scale 연구 실험이다. 국소 DOM 수집 시간과 모델 추론 시간을 직접 비교하지 않는다. 10개 OTT의 120화면/360필드를 수집하고 학습·개발·독립 검증을 나누었다. 현재 국소 수집 템플릿으로 다시 학습한 모델의 결과가 아니다.

같은 개발 검증 57필드를 구성별 새 Chromium에서 2회 실행했다. 시간은 추론이 필요한 56필드 기준이며 표의 범위는 두 실행값이지 통계적 신뢰구간이 아니다.

| 연구 모델 구성                  | 개발 정답 | p50 (ms)    | p95 (ms)    | 관측 최대 WS (MiB) | 종료 1초 후 WS (MiB) |
| ------------------------------- | --------- | ----------- | ----------- | ------------------ | -------------------- |
| 12층 자연어 · main/full         | 39/57     | 1,196–1,208 | 1,871–1,950 | 617–622            | 616–622              |
| 12층 자연어 · worker/micro2     | 39/57     | 1,023–1,035 | 1,715–1,810 | 605–606            | 467–471              |
| 12층 짧은 입력 · worker/micro2  | 33/57     | 510–524     | 936–1,019   | 597–598            | 465–475              |
| 4층 짧은 입력 · worker/micro2   | 33/57     | 175–205     | 331–344     | 575                | 472–473              |
| 4층 자연어 · worker/full (선택) | 42/57     | 411–424     | 632–685     | 613–617            | 476–477              |
| 4층 자연어 · worker/micro2      | 39/57     | 348–350     | 556–561     | 597                | 463–466              |

선택한 4층 자연어 worker/full은 12층 자연어 main/full 대비 두 실행 p50 평균이 약 65%, q8 모델 파일이 14.70MB→7.97MB로 약 46%, 종료 1초 후 WS 평균이 약 23% 줄었다. 전체 관측 최대 WS는 거의 같았다. 모델 깊이와 실행 구성이 함께 바뀌었으므로 worker 단독의 효과라고 해석하지 않는다.

이 실험은 Ryzen 7 8840U·Windows·Chromium 158.0.8127.18·ONNX Runtime Web 1.31.1·WASM 1 thread에서 수행했다. 시간은 토큰 변환·padding·정합 검사·텐서 생성·추론·결과 읽기·해제를 포함하고 DOM 수집·입력 문장 작성·모델 로딩·I/O는 제외한다. WS는 격리 Chromium 프로세스의 working set 합으로 브라우저 기본 비용과 공유 페이지 중복 계산을 포함한다. 설치된 확장의 추가 물리 메모리나 연속 peak RAM 측정이 아니다.

독립 검증에서 선택 모델의 실제 브라우저 정답은 **50/120(41.7%)**, 양성 추출은 **9/72(12.5%)**, 항상 NONE 기준선은 **48/120(40.0%)**였다. 작품 정보 세 필드를 모두 맞힌 양성 페이지는 **0/24**다. 별도 독립 실행의 처리 p50/p95는 **507/673ms**(추론 필요 118필드)였다. 속도 개선이 정확도 확보를 의미하지 않으므로 모델은 기본 확장 경로에 넣지 않았다.

## 5. 검증 상태와 알려진 한계

0.1.5 릴리즈 빌드에서 TypeScript·단위 테스트 413개·빌드·전체 브라우저 통합 테스트 30개를 새로 실행해 통과했다. 성능 수집 코드 자체는 기준 커밋과 같으며 위의 성능 수치는 기존 측정값이다.

배포 ZIP은 388,142B(379.0KiB), 내부 파일 10개이며 dist의 각 파일과 바이트 단위로 일치했다. ZIP을 새 디렉터리에 풀고 격리 Chromium 158의 새 프로필에 확장을 로드해 버전 0.1.5, 보관함, snapshot RPC를 확인했고 오류는 0개였다. ZIP SHA-256: 372c2c725dcca32fd018edca931fea6bacd3dbfdef57bd1dfa83d14f62d2fdee.

[테스트 릴리즈 v0.1.5](https://github.com/pnpcrow/animation-ott-switch/releases/tag/v0.1.5) · [패키지 검증 JSON](https://github.com/pnpcrow/animation-ott-switch/releases/download/v0.1.5/package-validation-0.1.5.json)

국소 수집기의 CPU/전체 브라우저 RAM 변화와 사이트 간 이동 완료 시간은 이번 자료에 없다. 이전 구현과 같은 페이지를 동일 조건으로 비교한 전후 시간 측정도 없다. 공개 DOM 3화면과 수작업 화면만으로 지원 OTT 전체의 정확도나 사이트 업데이트 내성을 보증하지 않는다. 기존 메타데이터와 어댑터를 보존하고, 누락된 값만 보수적으로 보완하는 단계다.
