# 0.1.1 · 검색 연결과 모달·미리보기 수정

2026-11-13 · 비공개 알파

- 검색어에 섞이던 `Watch` 시청 안내 문구를 제거했습니다. 실제 제목에 포함된 단어는 제목 근거를 비교해 보존합니다.
- 공식 검색 결과의 제목과 작품 ID를 확인해 작품 링크로 이동합니다. HTML·브라우저 검색 후보는 상세 페이지를 다시 검증하며, 라프텔 공개 카탈로그 API는 제목·작품 ID·제공 상태로 연결합니다. 자바스크립트로 표시되는 검색 결과는 임시 브라우저 탭에서 확인하고, 동명·자막·더빙 후보가 여러 개면 선택 후 검증합니다.
- 라프텔 홈·검색의 작품 모달과 Netflix의 상세 모달·단독 작품 페이지를 인식합니다. 모달의 제목·이미지·소개를 사용하고 같은 작품의 모달 내부 이동에서는 펼친 상태를 유지합니다.
- Prime Video 등에서 포스터가 자동 미리보기 영상으로 바뀔 때 사이드바가 사라지던 재생 감지를 수정했습니다. 실제 본편 재생·전체화면에서는 숨깁니다.

자동 브라우저 확인은 구독한 서비스에서만 실행합니다. 각 서비스의 **찾아서 이동**으로 개별 확인할 수 있습니다. 임시 탭은 동시에 최대 2개이며 일반 사이트 탐색과 동일하게 기존 로그인 상태를 사용할 수 있습니다. 쿠키·토큰을 읽지 않으며 사용자가 활성화한 탭은 자동 이동하거나 닫지 않습니다.

## 업데이트

`ott-switch-0.1.1.zip`을 풀어 기존에 로드한 폴더의 파일을 교체하고 `chrome://extensions`에서 확장 프로그램을 새로고침하세요. 열려 있는 OTT 페이지도 새로고침해야 새 콘텐츠 스크립트가 적용됩니다. 로컬 보관함을 유지하려면 확장 프로그램을 제거하지 마세요. 필요하면 먼저 JSON 백업을 내보내세요.

## 확인 범위

타입 검사, 단위 테스트 212개, 실제 MV3 확장을 로드한 브라우저 회귀 테스트 12개 및 빌드가 통과했습니다. 실제 공개 라프텔 검색 화면에서 모달 인식, 미리보기 중 유지, 모달 닫기 후 숨김도 확인했습니다. Netflix·Prime Video의 이번 검증은 재현 DOM을 사용했으며 각 서비스의 모든 로그인 계정 상태를 확인한 것은 아닙니다.

로그인 요구·접근 제한·제목 불일치·불완전한 검색 결과는 `확인 필요`로 남습니다. 작품 페이지의 존재는 한국 재생 권한이나 구독 포함 여부를 보증하지 않습니다. Google Drive 동기화와 Chrome 웹 스토어 출시는 이번 버전에 포함하지 않습니다.

GitHub Actions는 기존 계정 예산 제한으로 실행되지 않았습니다. 원격 CI 통과를 주장하지 않습니다.
