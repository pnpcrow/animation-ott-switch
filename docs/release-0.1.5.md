# v0.1.5 · 국소 DOM 수집과 성능 검사 보고서

2026-11-14 · 비공개 테스트 프리릴리즈

작품 영역 안에서 필요한 제목·소개·이미지만 제한된 주변 구조와 함께 읽도록 개선했습니다. 검색 링크가 옆 작품의 제목을 가져오는 문제를 막고, JS에 명시된 작품 주소도 상세 페이지를 확인한 뒤 이동합니다.

- 활성 작품/모달 범위에서 필드별로 점진 탐색하고, 후보 수와 노드 방문량을 제한합니다.
- 제목 이미지의 alt, 펼치기 버튼 안의 소개, 이미지의 실제 표시 크기와 부모 라벨을 보존합니다.
- 회차·추천·작은 로고를 구분하며, 여러 후보가 경쟁하거나 탐색이 잘리면 자동 선택을 보류합니다.
- 상대 XPath는 현재 DOM 스냅샷에만 사용하며, 비동기 응답 후 요소·값·가시성이 바뀌었으면 재수집합니다.
- `data-url`, `data-href`, 정적인 JS 이동 주소를 지원합니다. 불명확한 JS를 실행하지 않고 기존 제목·작품 ID·상세 검증을 유지합니다.
- 기존 메타데이터와 서비스 어댑터의 유효한 값을 우선하며 누락된 항목만 보완합니다. 모델 다운로드나 WebLLM 기본 실행을 추가하지 않았습니다.

## 성능 검사 결과

[한국어 전체 보고서](https://github.com/pnpcrow/animation-ott-switch/blob/v0.1.5/docs/performance-0.1.5.md)를 참고하세요. 릴리즈에 첨부한 `performance-0.1.5.html`은 내려받아 브라우저에서 바로 열 수 있습니다.

| 검사 | 기존 측정 결과 |
| --- | --- |
| 실제 수집 DOM 재생, 필드별 처리 시간 중앙값 | 라프텔 0.3–0.5ms / 프라임 1.0–1.6ms / 티빙 0.6–1.0ms |
| 기존 공개 DOM 3개 서비스의 주석 후보 회수 | 8/9 필드; 소개는 기존 주석의 접두어 일치 기준 |
| 합성 브라우저 사례 | 18개 필드 검사 통과, 주석 후보 17/17 회수 |
| 큰 모달 사례의 직렬화 입력 크기 | 전체 fixture HTML 58,414B / 필드별 JSON 세 개 합계 2,714B |
| 점진 탐색 사례 | 첫 후보까지 12회 방문 / 완전 탐색 807회 방문 |

처리 시간은 필드별 DOM 수집 시간이며 OTT 검색·네트워크·모델 추론 시간을 포함하지 않습니다. 재사용한 DOM은 개발 자료이며 새 블라인드 검증이 아닙니다. 입력 바이트 감소는 브라우저 RAM 절감 측정이 아니고, 작은 페이지에서는 문맥 JSON이 HTML보다 커집니다. 첫 후보 발견만으로 자동 선택하지 않습니다.

프라임의 주석 이미지 일부는 메타데이터/별도 picture 소스에 있어 현재 국소 수집기가 놓칩니다. 티빙은 정답 후보가 있어도 경쟁 후보 때문에 기본 선택기가 보류합니다. 기존 어댑터를 함께 사용하며, 모든 작품·계정의 자동 연결을 보장하는 버전은 아닙니다.

## 설치 및 업데이트

1. `ott-switch-0.1.5.zip`을 내려받아 압축을 풉니다.
2. 처음 설치한다면 Chrome의 `chrome://extensions`에서 개발자 모드를 켜고 **압축해제된 확장 프로그램을 로드합니다**로 `manifest.json`이 있는 폴더를 선택합니다.
3. 기존 설치를 업데이트한다면 같은 설치 폴더의 파일을 교체하고 확장을 **새로고침**합니다. 확장을 제거할 필요는 없습니다.
4. 열린 OTT 페이지도 새로고침합니다. 설정이나 사이드바의 검색 캐시 초기화를 사용하면 기존 검색 결과를 지우고 다시 시험할 수 있습니다.

북마크는 업데이트 전에 보관함의 JSON 백업으로 보관할 수 있습니다. 확장 제거나 다른 폴더/프로필로 이동하면 기존 로컬 데이터에 접근하지 못할 수 있으므로 같은 폴더에서 업데이트하세요.

## 릴리즈 검증

v0.1.5 빌드에서 타입 검사·단위 테스트 413개·브라우저 회귀 테스트 30개·프로덕션 빌드가 모두 통과했습니다. 브라우저 회귀는 격리 Chromium에서 고정 OTT DOM을 사용하는 검사이며, 실시간 로그인 계정 전체를 검증한 것은 아닙니다.

설치용 ZIP은 388,142바이트, 10개 파일이며 빌드 폴더와 바이트 단위로 일치합니다. ZIP에서 직접 압축 해제한 파일을 새 Chromium 프로필에 설치해 버전 0.1.5·서비스 워커·보관함·저장소 조회 RPC를 확인했고 페이지/콘솔 오류는 0건이었습니다. 학습 모델·수집 HTML·개인 데이터는 ZIP에 포함하지 않았습니다.

ZIP SHA-256: `372c2c725dcca32fd018edca931fea6bacd3dbfdef57bd1dfa83d14f62d2fdee`
