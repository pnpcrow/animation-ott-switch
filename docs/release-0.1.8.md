# AniOTT Switch 0.1.8

2026-11-14 · 일반 릴리즈

아이콘의 A와 화살표가 겹쳐 생기던 돌출부를 없애고, 좌우 대칭의 단일 윤곽으로 정리했습니다. 확장 아이콘·사이드바·스토어 아이콘·프로모션 타일에 같은 도형을 적용했습니다.

화면의 ‘내 라이브러리’·‘나의 작품’ 표현을 ‘작품 보관함’·‘저장한 작품’으로 바꾸고, 프로모션 문구도 **작품 보관부터 OTT 이동까지**로 정리했습니다.

스토어 캡처는 실제 작품과 공식 대표 이미지로 다시 만들었습니다. 《어느 마녀가 죽을 때까지》, 《장송의 프리렌》, 《외톨이 THE ROCK!》, 《극장판 스파이 패밀리 코드 : 화이트》, 《스킵과 로퍼》, 《마녀의 여행》을 사용합니다. 사이드바 캡처의 배경도 실제 라프텔 작품 화면입니다. 작품 설명은 짧게 요약했고 기능을 보여주기 위한 카테고리·메모만 별도로 구성했습니다.
