# 0.1.0 · 비공개 알파

2026-11-13

처음 발견한 OTT 작품을 내 구독 서비스에서 찾아 이동하고 카테고리별 보관함에 정리하는 첫 구현입니다.

- 10개 OTT 작품 주소 어댑터 및 공식 공개 검색.
- 접이식 오버레이, 북마크·카테고리 변경, 사용자 메타데이터 우선 표시.
- 3단 보관함, 직접 추가와 편집, 즐겨찾기·메모, 구독 서비스 및 새 탭 설정.
- IndexedDB 영속 저장, 원자적 연결 검증, 전체/그룹 JSON 백업·병합.
- 삭제 기록과 최신 수정 우선 정책, 단위/브라우저 테스트, CI 배포 artifact.

로그인·접근 차단·클라이언트 렌더링이 필요한 자동 검색은 `확인 필요`로 남습니다. 10개 모두에서 모든 작품의 자동 연결을 보증하지 않습니다. 작품 페이지는 구독 포함·한국 재생 가능성의 보증이 아닙니다. 리메이크에 연도 정보가 없거나 원제가 다르면 사용자의 확인과 별칭 입력이 필요할 수 있습니다.

Google Drive 동기화는 설계만 포함합니다. OAuth 연결과 원격 동기화는 다음 단계입니다. Chrome 웹 스토어 배포 및 공개 저장소 전환은 진행하지 않습니다.
