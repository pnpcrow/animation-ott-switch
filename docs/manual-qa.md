# 출시 전 서비스별 수동 검증

0.1.4는 비공개 알파입니다. 공개 응답·자동 테스트 외에 아래 항목은 실제 한국 계정으로 확인해야 합니다. 제공되지 않은 로그인 계정 테스트를 완료된 것으로 간주하지 않습니다. 8개 작품의 최신 검사 범위와 실제 성공·보류는 [교차 검사 기록](cross-check-2026-11-13.md)에 있습니다.

0.1.3에서는 실제 확장의 웨이브 검색부터 URL 없는 프로그램 카드 클릭, `programid=CF02_CF0000000119&landing=season` 상세 정보 검증, 최종 탭 이동까지 확인했습니다. 작품명은 `어느 마녀가 죽을 때까지`이며 제목·대표 이미지·전체 소개를 추출했습니다. 이 확인은 공개 페이지 기준이며 로그인 후 구독 권한·본편 재생은 별도 검증 대상입니다. Prime Video의 공식 `phrase` 검색 전달과 빈 상단 입력창 표시, 한국어 서비스명 장식 정제는 회귀 사례로 검사합니다.

0.1.2에서는 실제 검색 구현에 `Watch`가 붙은 한국어 제목과 Crunchyroll 홍보 문구 별칭을 입력해 라프텔 공개 API를 조회했습니다. `어느 마녀가 죽을 때까지`의 작품 주소 `https://laftel.net/item/42783`으로 연결 가능한 결과를 확인했으며, 검색 결과는 1개이고 만료되지 않은 제공 상태였습니다. Crunchyroll의 홈페이지 홍보 문구가 검색어가 되는 브라우저 경로와 `Watch` 재유입은 재현 DOM·응답으로 검사하며, 실제 로그인 상태의 Crunchyroll에서 왓챠까지의 이동을 실측한 것은 아닙니다.

0.1.1에서 실제 공개 라프텔 검색 화면의 `#item-modal` 열기·닫기와 자동 미리보기 중 사이드바 유지를 확인했습니다. Netflix 모달·단독 페이지, Prime Video의 포스터→미리보기 전환과 실제 컨트롤 영상 재생은 재현 DOM을 이용한 브라우저 회귀 테스트를 통과했습니다. 아래 계정별 현장 검증은 계속 필요합니다.

- 각 OTT 로그인 전/후, 성인 제한, 구독 유/무에서 제목·이미지·소개 확인.
- 첫 진입과 SPA 이동에서 이전 작품 메타데이터가 새 ID로 저장되지 않는지 확인.
- 검색·홈의 목록에서는 숨기고 작품 상세 모달을 열면 표시하는지 확인. 모달 닫기·다른 작품 열기·같은 작품의 내부 탭 이동을 확인.
- 전체화면, 음소거, 일시정지, 종료, Picture-in-Picture, iframe 플레이어의 숨김 상태 확인. 타 도메인 iframe 내부 재생은 현재 감지할 수 없어 별도 대응이 필요할 수 있음.
- 한국어/영어/일어 제목, 시즌·파트·극장판·리메이크, 자막/더빙 구분.
- Crunchyroll의 `어느 마녀가 죽을 때까지`에서 자동 검색·찾아서 이동·직접 검색으로 전달되는 제목을 비교. 원본 요청이 홈페이지 홍보 문구를 반환하거나 실패해도 작품 제목을 유지하는지 확인.
- 구버전 북마크의 `Watch`가 붙은 한국어 제목, 정상 `Watch Dogs`, 오염된 JSON-LD와 정상 화면 제목 조합을 확인. 사용자 지정 표시 제목·설명이 변경되지 않는지도 확인.
- 차단·로그인·빈 검색 셸을 작품 없음으로 오인하지 않는지 확인.
- Netflix의 browse/search/genre 모달과 단독 상세 간 전환 및 프로필 차이. 현재 URL에 식별 가능한 작품 ID가 없는 모달은 추가 대응이 필요할 수 있음.
- Prime Video 로그인 상태의 자동 미리보기 중 접힌 버튼·펼친 사이드바 유지. 커스텀 본편 플레이어의 탐색 컨트롤·전체화면·일시정지별 숨김을 확인.
- Prime Video 직접 검색·찾아서 이동의 URL 검색어와 실제 결과를 확인. 공식 검색창이 처음 비어 있으면 검색어를 표시하되 자동 제출·포커스 이동·사용자가 지운 값의 재입력이 없는지 확인.
- 임시 검색 탭에서 로그인·접근 제한·느린 로딩이 `작품 없음`으로 확정되지 않는지 확인. 검색 결과와 상세 제목이 달라지면 스위치하지 않는지 확인.
- 임시 탭을 사용자가 활성화하거나 다른 페이지로 이동했을 때 확장이 그 탭을 자동 이동·종료하지 않는지 확인.
- 웨이브 VOD/영화 query ID, 회차와 작품 그룹, 플레이어 DOM.
- 웨이브의 프로그램·영화·에피소드·에디터 추천을 구분하고 프로그램 카드 클릭 후 시즌 진입 주소를 유지하는지 확인. 동명 카드가 여러 개이거나 상세 제목이 다르면 최종 이동하지 않아야 함.
- 설정·사이드바의 검색 캐시 초기화 후 자동 검색 링크만 제거되고 수동·현재 페이지 링크와 북마크 정보가 보존되는지 확인. 초기화 전 요청의 늦은 응답이 이동·캐시 복원을 일으키지 않고 사이트 로그인은 유지되어야 함.
- 쿠팡플레이 지원 브라우저 안내와 로그인 DOM.
- Apple TV/Prime의 구독·채널·대여/구매·한국 판권 차이.
- Crunchyroll 한국 계정의 실제 작품별 라이선스 범위.
- 대량 작품 저장 성능, 다른 프로필 백업 복원, 같은 폴더 업데이트 후 DB 보존.
- Drive 구현 시 기기 시계 오차·동시 쓰기·오프라인·계정 전환·ETag 충돌.
- 기본 기능은 WebLLM 미사용 상태에서 검증. WebLLM 도입은 이후 선택 기능으로 진행하며 모델 다운로드·성능 요구로 기본 검색이 제한되지 않아야 함.

Chrome 웹 스토어 제출 전에는 실제 서비스 QA와 개인정보 표시·권한·상표/이미지 사용 범위를 다시 검토합니다.
