기본 선택기는 5개를 기존 정답과 일치하게 선택하고 4개를 보류했습니다. 티빙은 정답 후보가 있어도 작품·회차와 이미지·설명 후보가 경쟁하므로 세 필드 모두 보류했습니다.

누락한 프라임 이미지

기존 정답 이미지가 메타데이터나 picture의 다른 소스에 있어 img.src/video.poster 기반 수집에서는 찾지 못했습니다. 기존 메타데이터·서비스 어댑터를 계속 사용합니다.

이 자료를 보며 제목 이미지 alt와 소개 펼치기 버튼 지원을 보완했습니다. 따라서 새로운 서비스·작품에 대한 블라인드 평가가 아닙니다.

03 · HISTORICAL MODEL RESEARCH

이번 릴리즈의 기본 경로에 미적용

이 표는 별도 동결한 KoELECTRA 기반 연구 결과입니다. 현재 국소 DOM 템플릿으로 다시 학습한 결과가 아니며 위의 수집 시간과 직접 비교하지 않습니다. 같은 개발 검증 57필드를 구성별 새 Chromium에서 두 번 실행했습니다. 시간은 추론이 필요한 56필드 기준입니다.

항상 NONE 기준선 48/120(40.0%)에 가깝습니다. 양성 추출은 9/72(12.5%), 세 필드를 모두 맞힌 양성 페이지는 0/24였습니다. 별도 독립 실행의 p50/p95는 507/673ms(추론 필요 118필드)였습니다. 빠른 실행만으로 기본 기능에 적용하지 않았습니다.

WS는 격리 Chromium 프로세스의 working set 합입니다. 기본 브라우저 비용과 공유 페이지 중복 계산이 포함되어 실제 확장의 추가 물리 메모리나 연속 peak RAM으로 볼 수 없습니다.
