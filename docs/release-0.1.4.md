# 0.1.4 · 8작품 교차 검증과 선택형 모델 평가

2026-11-13 · 비공개 알파

8개 작품을 10개 OTT에서 조사하고, 실제 확장에서 출발 페이지를 읽어 다른 서비스로 검색·이동하는 경로를 검사했습니다. [전체 결과와 재현 명령](cross-check-2026-11-13.md)에 공식 카탈로그 근거, 로그인·접근 제한, 실제 이동과 후보 선택을 구분해 기록했습니다.

- 애니플러스: URL 없는 검색 카드를 정상 클릭하고 상세 레이어의 제목·일본어 별칭·이미지·소개를 읽습니다. 뒤에 남아 있는 검색 제목과 홈페이지 문구를 작품으로 저장하지 않습니다.
- 티빙: 실제 카드 제목을 `포스터` 이미지 설명보다 우선합니다. 상세 페이지의 작품 로고와 메타데이터를 대조해 회차 문구를 작품명과 구별합니다.
- 자막·더빙 표기가 제목 앞이나 뒤에 있어도 일관되게 비교합니다. 여러 버전이 있으면 임의로 선택하지 않습니다. 시즌·감독판·총집편은 유지합니다.
- Apple TV의 웹 검색에서 누락된 작품을 카탈로그 전체의 부재로 단정하지 않습니다. 없는 이미지가 HTML 페이지 주소로 바뀌는 문제와 `{줄거리}` 같은 미작성 소개도 처리했습니다.

[선택형 WebLLM 평가 도구](../eval/webllm/README.md)는 기본 확장과 별도입니다. 명시적인 모델 다운로드, WebGPU 실행, 관측 자료 수집, 버전별 프롬프트, 조정용/독립 검증용 자료 분리, 실제 응답·오류·점수 내보내기를 제공합니다. 실제 모델 평가 결과는 [평가 기록](../eval/webllm/RESULTS.md)에 있습니다. 모델이 관측되지 않은 URL을 만들거나 직접 이동을 실행하지 않으며, 이번 확장은 기존 규칙으로 동작합니다.

로컬 타입 검사·빌드, 단위 테스트 339개, 브라우저 회귀 테스트 28개, 선택 평가 도구 검사 7개가 통과했습니다. 실제 모델의 정답 일치 평가는 테스트 통과와 별도로 기록했으며, 평가한 세 모델은 자동 이동에 채택하지 않았습니다.

기존 설치 폴더에 ZIP 내용을 교체한 뒤 `chrome://extensions`에서 확장과 열린 OTT 페이지를 새로고침하세요. 북마크 보존을 위해 확장을 제거할 필요는 없습니다. 계정별 재생 권한과 전체 카탈로그의 호환성을 보증하는 버전은 아닙니다.
