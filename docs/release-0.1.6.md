# v0.1.6 · 스토어 ID 고정 패치

2026-11-14 · 비공개 테스트 프리릴리즈

v0.1.5로 생성한 기존 Chrome 웹 스토어 항목의 공개키를 확장에 적용했습니다. **고정 확장 ID는 `cmaijknliglhgokkmijggladebokgafl`입니다.** 앞으로 패키지 버전과 설치 폴더가 바뀌어도 이 키를 유지합니다.

- `manifest.key`에 실제 스토어 공개키를 추가했습니다. 새 키나 새 스토어 항목을 만들지 않았습니다.
- 공개키 해시·ID·제품 이름·package name을 고정 기준과 대조합니다. 키 삭제/교체, 잘못된 ID, 소스와 dist의 버전/키 불일치는 빌드·패키징에서 실패합니다.
- 기존 IndexedDB 이름, 저장 레코드와 카테고리 ID, 기기 ID, 백업 형식을 유지했습니다.
- v0.1.5 태그와 ZIP은 그대로 보존합니다. 이번 패치는 식별 설정을 구분하기 위해 버전만 0.1.6으로 올렸습니다. DOM 추출·검색·모델 동작은 v0.1.5와 같습니다.

## 기존 로컬 설치에서 전환

기존 v0.1.5 ZIP은 공개키가 없어서 압축 해제 설치의 ID가 폴더 경로에 따라 달랐습니다. 현재 설치 ID가 위 고정 ID와 다르다면 **기존 보관함의 전체 JSON 백업을 먼저 내보내고**, 0.1.6을 설치한 뒤 가져오세요. 서로 다른 확장 ID의 저장소를 자동으로 읽을 수는 없습니다. 백업 확보 전에 기존 확장을 제거하지 마세요.

이미 ID가 같거나 고정 ID 적용 후 업데이트한다면 기존 설치 폴더의 파일을 교체하고 Chrome 확장 관리 화면에서 새로고침합니다. 열려 있는 OTT 페이지도 새로고침하세요. Chrome 프로필을 새로 만드는 경우는 별도 저장소이므로 백업·가져오기를 사용합니다.

## 스토어 등록과 이후 업데이트

현재 개발자 대시보드에 있는 **기존 항목 `cmaijknliglhgokkmijggladebokgafl`의 새 패키지 업로드**로 `ott-switch-0.1.6.zip`을 사용하면 됩니다. 버전 번호는 업데이트 때 올리지만 ID와 공개키는 바꾸지 않습니다. 이 작업에서는 등록정보 작성이나 검토 제출을 수행하지 않았습니다.

구현 규칙과 공개키 출처는 [식별자 고정 문서](https://github.com/pnpcrow/animation-ott-switch/blob/v0.1.6/docs/extension-identity.md)에 있습니다. 성능 수집 코드는 변경하지 않았으며 기존 [v0.1.5 성능 보고서](https://github.com/pnpcrow/animation-ott-switch/blob/v0.1.5/docs/performance-0.1.5.md)를 그대로 참고할 수 있습니다.

## 검증
